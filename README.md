# 余波 · AFTERWAVE

一款面向手机竖屏的原创历史干预策略叙事游戏。进入一个地方，改变一套规则，再面对由此过上不同人生的人。

## 运行

需要 Node.js 22.12+（开发环境实测 Node 24）。

```sh
npm ci
npm run dev
```

打开终端显示的本地地址。手机访问需要在可信局域网中使用 `npm run dev -- --host 0.0.0.0`。本仓库保持私有，不自动开启公开部署。

```sh
npm test             # 确定性内核测试
npm run test:browser # Chromium 完整流程、响应式与键盘/镜头交互测试
npm run test:interactions # 单独运行交互与首屏主行动回归
npm run build       # 静态站点产物 dist/
npm run preview     # 检查生产构建
```

构建文件使用相对路径，可托管到静态服务器。不要直接双击 dist/index.html；浏览器对 file:// 模块加载的限制会阻止启动。GitHub Actions 验证通过后提供包含 dist 与测试截图的 `afterwave-playable-build` 私有构建附件。

## 如何玩

1. 观察 8×8 固定地理。四个通道是独立的能力值，不是四个互斥阵营。
2. 通过地图或完整坐标列表选择地域。地图点击不会消费名额。
3. 进入 AVG，调查证据，预览治理方案与成本。
4. **锁定只保存草稿。** 全部棋子锁定或明确放弃后，才统一提交。第20年可统一对照复核成功/未完成、停闸后备和逐地预警，不能借预览重掷。
5. 每年结算，到第 10/20/30 年再介入，第 40 年给阶段结局。
6. 档案中追踪来源，比较旧现实和当前现实；危机追踪分开发现渠道、实际回应和历史损失。没有高级回溯，也不能读档重掷。

第 0 年有主角一名；林澈需自愿入局，且下一窗口才可部署。实际存在岗位时，带走她会留下维护与继任代价；没有岗位时提供事实准确的自愿同行合同。危机在第 14 年预警，第 20 年有实际可用的缓解行动，第 23 年可能造成不可逆地方损失。

## 已实现

- 64 格 × 四通道、固定 2:1 棋盘，选择/聚焦/拖动/完整列表。
- 三种建站制度、一次到期概率、失败档案站、D4→E4/D5→F6 可追溯预设事件链。
- 四个介入窗口和第 40 年实际阶段结局、维护、继任、同伴、旧现实冲突、共同失效危机。
- 同窗快照、原子提交、确定性年度内核、稳定事件 ID、存档恢复、逐年/自动/跳转播放。
- 七个核心界面、完整中文 AVG、200% 字体设置、320/360/390/430 宽度测试、键盘可用的列表与按钮。
- 本地自动存档、JSON 导入导出、种子选择。

## 诚实的边界

这是可玩原型，不是已完成商业美术和真人平衡验证的正式发行。首轮工程建筑素材沿用交接包的原创代理素材；档案室场景是新制作的原创 SVG。故事与数值仍在迭代。未实现高级回溯、全面战争、复杂贸易、64 格各自完整 AVG、音效和正式角色肖像。没有执行真人试玩、真实手机设备测试或无障碍认证。

三个治理方向当前均可建立预设教学链，区别体现在成本、启用概率、产出、开放覆盖、来源保护和实际危机损失。覆盖与损失权重是本轮新增的可调原型假设，不是已验证的历史结论或原交接既定数值；更深的专属支线和角色关系仍待扩展。详见[治理与覆盖假设](docs/GOVERNANCE_ASSUMPTIONS.md)。持续风险目前通过明确的维护/危机时点表达，未实现随机年度查封。预测区明确标记未发生，不伪造数值预测。

详见 [实现与自评](docs/IMPLEMENTATION.md) 和 [实际测试记录](docs/TESTING.md)。

## 数据与来源

用户提供的《余波》交接包 v0.3 是设计基线。`src/data/board.json` 保留原始 64 格示例。游戏存档版本为 `afterwave.run.v1`。设计数值是可调整的游戏假设，不是现实历史预测。

原创人物与剧情不复用参考作品的人物或文本。美术来源见 [资产说明](docs/ASSETS.md)。不包含遥测、广告或外部账户系统。

## 本轮三方面改进

玩法以提前准备、复核风险、确定停闸和有限调查形成取舍，保留不建站但有准备的有效路线；林澈视角与主角亲历分开；场景插画和地图机构状态跟随真实历史。新行动规则只应用于新局，旧档保留原合同。[具体假设与固定种子比较](docs/TRADEOFFS_ASSUMPTIONS.md)。

### 交班与后果回访迭代

既有学徒现在按真实人手参与交班，独立校验和地方授权分别核对，不靠机构总数加分。第30年对白回应实际危机与苏岚选择，河堤课堂有对应原创道具和停办痕迹。[交班规则与兼容边界](docs/HANDOFF_ASSUMPTIONS.md)。

### 同伴与停运痕迹迭代

林澈依据真实招募承诺拒绝亲自强制迁任；互助合同区分危机前减损与之后的持续生计。D4测站停运后保留原址与旧记录，不再画成从未建成。[角色边界、互助时点及旧档兼容](docs/AFTERMATH_ASSUMPTIONS.md)。

### 真实岗位与人物尾声迭代

没有D4在岗职责时，只提供事实准确的自愿同行合同；真实测站/档案仍保留继任取舍。第40年以可追溯的个人尾声回收林澈入局、岗位缺口与补救，以及苏岚的实际选择，不改变旧结局分数。地图把缺人和维护不足分开表现。[本轮规则、叙事及兼容边界](docs/RECRUITMENT_ASSUMPTIONS.md)。

## 第六轮只读信息改进

第20年整轮风险对照沿用实际合同概率，分别列成功与未完成分支、最强停闸后备和四地覆盖；旧版仍用原整体公式。地图空心方筹/圆筹表示主角/林澈的拟派遣，沙漏表示各地待兑现，不冒充已生效机构。危机来源链接保留原档案，补入真实复核/停闸等回应，建站链不再被误称致灾原因。[边界与假设](docs/OUTLOOK_ASSUMPTIONS.md)。
