# 余波 · AFTERWAVE

一款面向手机竖屏的原创历史干预策略叙事游戏。进入一个地方，改变一套规则，再面对由此过上不同人生的人。

## 运行

需要 Node.js 22.12+（开发环境实测 Node 24）。

```sh
npm ci
npm run dev
```

打开终端显示的本地地址。手机访问需要在可信局域网中使用 `npm run dev -- --host 0.0.0.0`。本仓库保持私有，不自动开启公开部署。

```sh
npm test             # 确定性内核测试
npm run test:browser # Chromium 完整流程、响应式与键盘/镜头交互测试
npm run test:interactions # 单独运行交互与首屏主行动回归
npm run build       # 静态站点产物 dist/
npm run preview     # 检查生产构建
```

构建文件使用相对路径，可托管到静态服务器。不要直接双击 dist/index.html；浏览器对 file:// 模块加载的限制会阻止启动。GitHub Actions 验证通过后提供包含 dist 与测试截图的 `afterwave-playable-build` 私有构建附件。

## 如何玩

1. 观察 8×8 固定地理。四个通道是独立的能力值，不是四个互斥阵营。
2. 通过地图或完整坐标列表选择地域。地图点击不会消费名额。
3. 进入 AVG，先阅读合同与条件比较，再花调查轮次取得证据。第20年B4/F6可在取证前比较复核、强化停闸与基本停闸；其他角色未安排时保留未知。
4. **锁定只保存草稿。** 全部棋子锁定或明确放弃后，才统一提交。第20年可统一对照复核成功/未完成、停闸后备和逐地预警，不能借预览重掷。
5. 每年结算，到第 10/20/30 年再介入，第 40 年给阶段结局。
6. 档案中追踪来源，比较旧现实和当前现实；也可在回放和结局回访D4、E4、B4、D5、F6，查看已兑现选择与当前服务。危机追踪分开发现渠道、实际回应和历史损失。没有高级回溯，也不能读档重掷。

第 0 年有主角一名；林澈需自愿入局，且下一窗口才可部署。实际存在岗位时，带走她会留下维护与继任代价；没有岗位时提供事实准确的自愿同行合同。危机在第 14 年预警，第 20 年有实际可用的缓解行动，第 23 年可能造成不可逆地方损失。

## 诚实的边界

这是可玩原型，不是已完成商业美术和真人平衡验证的正式发行。首轮工程建筑素材沿用交接包的原创代理素材；档案室场景是新制作的原创 SVG。故事与数值仍在迭代。未实现高级回溯、全面战争、复杂贸易、64 格各自完整 AVG、音效和正式角色肖像。没有执行真人试玩、真实手机设备测试或无障碍认证。

三个治理方向当前均可建立预设教学链，区别体现在成本、启用概率、产出、开放覆盖、来源保护和实际危机损失。覆盖与损失权重是本轮新增的可调原型假设，不是已验证的历史结论或原交接既定数值；更深的专属支线和角色关系仍待扩展。详见[治理与覆盖假设](docs/GOVERNANCE_ASSUMPTIONS.md)。持续风险目前通过明确的维护/危机时点表达，未实现随机年度查封。预测区明确标记未发生，不伪造数值预测。

详见 [实现与自评](docs/IMPLEMENTATION.md) 和 [实际测试记录](docs/TESTING.md)。

## 本轮三方面改进

玩法以提前准备、复核风险、确定停闸和有限调查形成取舍，保留不建站但有准备的有效路线；林澈视角与主角亲历分开；场景插画和地图机构状态跟随真实历史。新行动规则只应用于新局，旧档保留原合同。[具体假设与固定种子比较](docs/TRADEOFFS_ASSUMPTIONS.md)。

### 交班与后果回访迭代

既有学徒现在按真实人手参与交班，独立校验和地方授权分别核对，不靠机构总数加分。第30年对白回应实际危机与苏岚选择，河堤课堂有对应原创道具和停办痕迹。[交班规则与兼容边界](docs/HANDOFF_ASSUMPTIONS.md)。

### 同伴与停运痕迹迭代

林澈依据真实招募承诺拒绝亲自强制迁任；互助合同区分危机前减损与之后的持续生计。D4测站停运后保留原址与旧记录，不再画成从未建成。[角色边界、互助时点及旧档兼容](docs/AFTERMATH_ASSUMPTIONS.md)。

### 真实岗位与人物尾声迭代

没有D4在岗职责时，只提供事实准确的自愿同行合同；真实测站/档案仍保留继任取舍。第40年以可追溯的个人尾声回收林澈入局、岗位缺口与补救，以及苏岚的实际选择，不改变旧结局分数。地图把缺人和维护不足分开表现。[本轮规则、叙事及兼容边界](docs/RECRUITMENT_ASSUMPTIONS.md)。

## 第六轮只读信息改进

第20年整轮风险对照沿用实际合同概率，分别列成功与未完成分支、最强停闸后备和四地覆盖；旧版仍用原整体公式。地图空心方筹/圆筹表示主角/林澈的拟派遣，沙漏表示各地待兑现，不冒充已生效机构。危机来源链接保留原档案，补入真实复核/停闸等回应，建站链不再被误称致灾原因。[边界与假设](docs/OUTLOOK_ASSUMPTIONS.md)。

## 第七轮：接续未完成的工作

新局第30年可为真实失败记录支付后续校验成本，第32年需实际人手与原记录仍可用。它只建立未来能力，保留第23年损失，交班仍需培训、授权和方针。十年回顾明确展示上一窗口选择、兑现与责任；南岸互助和教学在地图/近景中各自开闭。[设计与兼容边界](docs/RECOVERY_ASSUMPTIONS.md)。

第八轮增加第30年整轮交班条件对照、林澈同行后的真实行动尾声及F6分站/校验历史共存，模拟与存档规则未变。见[假设和边界](docs/HANDOFF_OUTLOOK_ASSUMPTIONS.md)。

第九轮增加有成本的远港公开预警协商、林澈对真实迁任/尊重选择的关系回应，以及D4居民钟报三态近景。新合同仅用于新局，旧档与23年历史保留。见[设计假设和验证边界](docs/PORT_ACCESS_ASSUMPTIONS.md)。

第十轮允许先免费读完整合同再决定取证，缺证据仍不能锁定；苏岚的职位按真实个人来源显示，南岸以独立历史页签回收第23年清点而不编造废墟。模拟与旧规则不变。见[阅读与来源边界](docs/READING_ASSUMPTIONS.md)。

### 第十五轮：未来校验与地方回访

新局在第30年可为缺少可用方法的B4从零筹备未来校验席：新投入与第34年实际人手条件，不借用不存在的失败底稿，也不改第23年。旧局保持原合同，已有有效方法或可接续底稿时不收重复建设费。规则及参数假设见[未来校验说明](docs/FUTURE_CHECK_ASSUMPTIONS.md)。

### 保档升级、清点地图与真实回顾

第30年可把来源完整且仍在维护的B4地方保档接成未来指令校验席：经济5、科学3、三轮取证与一个名额，第33年还要核对原档及实际测量人手。它不会重算第23年，也不会增加第二个交班地域；整轮对照分别显示已有方法与完成指令校验的能力。十年回顾记录实际兑现、取消原因与成本。地图用不同形状区分已预警、已存损失、零值与未知，图例和坐标列表同步可读。规则与兼容范围见[保档升级说明](docs/ARCHIVE_UPGRADE_ASSUMPTIONS.md)。

### 调查前条件比较

第20年B4/F6的现场与免费合同页新增只读比较：保留其他角色的真实安排，分别列出调查需用/剩余轮数、当地成本、到期年，以及复核成功和未完成时的整轮条件后果。调查已花不退，预算不足的路线明确不可达；未安排、冲突、余额不足或未知待兑现合同不会被默认为可计算。此表不取得材料、不锁定任务、不预测随机结果，已锁草案仍以原证据快照为准。采用原整体危机或原场景调查规则的旧档继续原流程；已有逐地危机与三轮调查规则的旧局可读取本表，不迁移存档。详见[比较边界](docs/INVESTIGATION_COMPARISON_DESIGN.md)。

### 让已有学徒取得承接权

新版新局第30年可在E4协商原学徒的地方承接权：政治3、经济2、一次当地居民取证与一个行动名额，第31年核对指定原培训点。它只授权已有学徒，不新建学校、不增加人手或预警覆盖，也不补出独立校验或河港信任；可以与“培育轮值维护者”的扩建路线比较。目标停运、来源不符或已获授权时取消，筹备成本不退。原版本旧档继续原合同。

D4与E4新增只读现场回访，显示实际已付合同、兑现/取消、当前机构与人物来源。东岸原培训点与后来学校的运行状态分开展示，议事桌区分待落实、已签署、取消与未知；锁定草案不会提前画成授权。过去的危机记录仍留在原页。

### 先看选择，再花调查

现场现在先列可免费阅读的行动与最低取证门槛，再进入真实调查。每份材料标出本地用途、是否可携往其他地点、调查后的余额，以及这一次会新关闭的路线；合同预览区分“尚未调查”和“本窗口轮次已不够”。基本停闸与可选强化分别说明，不能把别处的退路当作本地仍可用的行动。原预算、成本、锁定快照和旧档规则保持不变。

地点提问与材料名称围绕当前真正可谈的决定；未读正文仍需实际调查，条件不等于签名。既有第20年条件比较采用紧凑摘要与可展开详情，历史清点不再挤在当前选择之前。设计依据及仍待评估的晚期取舍见[取证规划说明](docs/INVESTIGATION_PLANNING_NOTES.md)。

### 最后一次介入，后来怎样了

第30年E4可在行动卡旁展开原学徒授权与新增培训的公开比较：两种投入、最低取证、承接对象、年度来源和覆盖条件分别说明。同地扩容不会多算一个自治地域，新增产出也不是未来通道净增；不把省下费用说成必然的长期优势。本轮644组自然对照显示当前数值仍偏向新增培训，未以信息改进冒称完成平衡。

第40年先读简短的实际收束、最后一次工作与人物末页，再按需展开完整原评语和技术账册。9种原创静物按已存事实区分授权文书、新培训器具、未签页、取消与停运，不替人物补写同意。查来源或回访后可返回刚才的结局位置；刷新后沿原档案/世界入口继续阅读。规则、历史和默认人物原文保留。设计依据见[第20轮评估](docs/ROUND20_DESIGN_REVIEW.md)。

### 第二十一轮：承接的是哪一种工作

新局第30年可与原东岸学徒协商轮值职责：保留基本读尺与预警，把部分深入带教转为议事和生计协调，政治、经济年度来源提高，科学来源减少。另选新培训则保留原点，新增教学载体。免费比较把科学代价、取消不退费和最后名额放在同层；主角选择其中一项，就不能同时签署交班方针。所有旧局保留原授权合同与年度结算，不自动改排。

这修正了已发现的自然样本全通道支配，不是完成全局或真人平衡的声明。设计见[本轮评估](docs/ROUND21_DESIGN_REVIEW.md)、[职责规则与兼容边界](docs/TRAINING_WORKLOAD_DESIGN.md)、[叙事](docs/TRAINING_WORKLOAD_NARRATIVE.md)和[移动端比较](docs/TRAINING_WORKLOAD_VISUALS.md)。`npm run test:training-choice-balance`重跑当前自然对照；`npm run test:training-choice-balance:round20`用冻结的真实旧生产者复现第20轮结论。

## 第二十二轮：清楚地作出最后决定

本轮不改变模拟、旧档或历史结果。见[实际体验与设计](docs/ROUND22_DESIGN_REVIEW.md)、[阶段叙事说明](docs/DECISION_STAGES.md)与[自然角色分配对照](docs/ROUND22_ROLE_OPPORTUNITY_AUDIT.md)。

### 第23轮：让已发生的结果留在阅读路径里

### 第二十四轮：同一轮时间，也属于别处

展开一份尚未调查的材料，会提前说明本次取证新关闭的异地方案：地点、仍需轮数和本角色的剩余预算逐项对照。可携材料会抵扣其他地点的真实需求，本地证词不因同名而通用；基本停闸与追加强化分开，另一角色的调查轮数不会被一起扣走。这只核对取证，不替你保证费用、名额、同格安排或未来结果。旧场景预算档继续原流程。

现场首屏可以免费跳到方案或取证用途，完整故事仍留在原处。读合同后返回原方案卡、展开项和阅读位置；这些临时位置不跨新局、导入或刷新。迁任卡默认展示真实收益、风险、东岸去向及河港制度范围，不把旧措辞里的“失去维护”当成没有停用后果，也不为不存在的岗位编造损失。

没有修改模拟、随机、成本、存档格式或已有历史。详见[跨地点调查边界](docs/CROSS_LOCATION_INVESTIGATION.md)、[视觉与阅读路径](docs/ROUND24_INVESTIGATION_VISUALS.md)、[叙事核对](docs/ROUND24_STORY_REVIEW.md)及[独立验收](docs/ROUND24_QA_REVIEW.md)。
