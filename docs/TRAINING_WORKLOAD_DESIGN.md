# 第二十一轮：承接职责也占用人的时间

## 先改变工作，再检验数字

第20轮已确认：在种子0–19、三类建站、两类招募与八种第20年安排中，有644组原学徒授权与新培训都可选的自然路线。旧规则的新培训在第40年E4四通道全高，两项的交班资格与预警覆盖相同。小额维护费不能解决这个问题：通道会回归基线，第30年以后没有下一次介入可以使用节省的余额。

本轮不把授权当作免费产出，也不让新学校遭遇种子决定的隐藏惩罚。新的协商合同明确包含一份工作分配：原东岸学徒取得本地承接权后，把大部分深入带教时间转入公开轮值、议事与生计协调，保留常规读尺。玩家付出的代价是少做深入带教，不是无损得到另一份工作。

只有提交这份新合同、在第31年真实兑现、且仍在运行的指定原培训点才改变年度来源。原学徒没有增员，D5同源学徒不被连带授权；预警覆盖、异源校验、河港信任与已经发生的第23年损失均不因此改变。新学校仍增加教学载体和原本的年度来源。

## 已选择的可调原型

按政治、经济、科学、宗教顺序：

- 原培训点年度基底：0.1 / 0.25 / 0.7 / 0.1。
- 本地承接轮值：0.5 / 0.45 / 0.1 / 0.1。
- 原点重排差值：+0.4 / +0.2 / −0.6 / 0，仍乘这一个原点的实际维护系数。
- 新学校独立新增：0.1 / 0.25 / 0.65 / 0.2。原培训点保持原来的深入带教工作。

两份原点向量的数值和相同，是防止把四项都提高的原型约束，不表示不同通道具有相同单位，也不是经济资源守恒证明。这些来源系数是设计假设，不是对真实社会生产率的测量。

原学徒的科学来源从0.7降到0.1是明显代价，必须在调查前说明“大部分深入带教转入轮值职责”。不能只写“授权提升协调”，把减少的教学藏进结局数字。年度来源也不是下一年或第40年通道的净增量。

## 自然路径实验

临时原型先复跑了与第20轮相同的644组真实调查、锁定、提交、逐年推进路线；生产脚本为 `node scripts/round21-training-choice-balance.mjs`，结果写入 `playtest-output/round21-training-choice-balance-results.json`。不以直接改余额的合成世界替代自然样本。

原型的第40年“新培训减原学徒承接”差值：

- 政治 −0.6740 至 −0.6737。
- 经济 −0.7084 至 −0.7080。
- 科学 +8.5513 至 +8.5517。
- 宗教 +1.5432 至 +1.5434。

644组均至少一维各有优势，而不是将数值支配反转成授权四通道全高。结局标题、交班资格、四地覆盖与第23年历史保持同一组对照中的原有关系。52组复核失败仍然失败，授权不替它们制造校验能力。

代表路线：种子0，联合建站、安排继任、B4完整复核与D4免费预警、最后共享方针。第40年承接轮值为56.1978 / 49.2121 / 38.2526 / 50.4912，新培训为55.5240 / 48.5038 / 46.8042 / 52.0346。新培训科学第32年反超；承接轮值政治第38年反超，其经济在这最后十年始终高于新培训。这是一个自然例子，不是对所有合法状态的最优性证明。

维护边界另作合成实验并明确标记：

- 原点维护0.5时，新培训仍四通道全高，且覆盖为0.55，对照原点的0.275。
- 维护0.6时，承接只在经济保留小幅优势，新学校仍补足覆盖。
- 维护1时，承接在政治、经济有优势，新培训在科学、宗教有优势。

这意味着旧原点必须真实运转，授权不能无视维护给出一份保底优势。自然样本原点的维护情况并不证明所有合法低维护状态都可自然到达。

这些结果回答了已发现的样本数值支配，但不构成“整个游戏已平衡”或真人选择验证。现有结局标题和资格依然不能概括所有玩家目标，后续应观察玩家是否理解带教减少及轮值责任，而不是只记住一组数值。

## 另外比较过的机制

1. **只转向公共议事。** 将原点改为0.5 / 0.25 / 0.3 / 0.1，保留更多教学、不增加经济来源。644组也出现政治与其余通道的交叉。它更简洁，但生计轮值在玩法中没有单独表现。本轮采用明确同时包含议事与生计协调的合同，并如实披露更大的教学代价。
2. **开班与独立毕业分开。** 若新培训第31年开办、第41年才具有独立承接资格，早投资与原学徒经验会更重要。但在当前644组中，原有160个共享合格、316个退出合格的新校分支将全部失去相应资格；当前窗口也没有办法继续补办。这种改动相当于重新设计终局培养周期，影响远大于当前问题，暂不采用。上述计数是对现有资格的条件分析，不宣称实现过完整的新毕业引擎。

短期减产、小额收费、另造一次末期灾难都没有本轮已存在的自然任务支撑，不作为已验证机制发布。

## 玩家在调查前可以核对什么

`getTrainingAuthorizationPlan(state).workload` 与 `getTrainingChoiceComparison` 只读当前公开规则和原培训点资料。新合同展示原向量、兑现后向量、差值、当前维护缩放及真实兑现条件。最低取证仍为E4居民证词1轮，成本仍为政治3、经济2，一个角色名额；新培训仍为经济4、科学2，无最低取证要求，一个角色名额。

比较的每个选项新增：

- `workload.before/after/delta`：原点未维护缩放的来源及变化。
- `workload.maintenance` 与 `scaledBefore/scaledAfter/scaledDelta`：当前维护条件下的原点贡献。
- `annualSourceAdded`：新增机构来源，授权为零，新培训为学校向量，保持原接口语义。
- `annualSourceChange`：上述原点变化加新增机构来源，不是假造未来通道余额。

新培训选项仍显示原点保持原工作，不以新增学校改写原学徒是否同意承接。旧规则授权选项明确没有工作重排。只读接口不读种子、抽样、调查库存、草案、未读正文或未来快照，不取证、不支付、不改锁定。

## 合同与兼容边界

- 仅 `createRun` 写入 `trainingWorkloadRulesVersion: training-workload-v1`。不迁移、补写或凭年代推断旧局身份。
- 没有该标记的旧局保留原授权合同、原向量、原grant、原历史文字及未来结算。第30年规划、已锁定、已提交、第31年、第35年和结局恢复都必须逐年比较完整state，而不是只比较最终标题。
- 新合同的行动、事件、兑现记录各保存独立的 `trainingWorkload`，包含版本、精确目标ID、标准before和after。成功grant另带对应版本。目标、原来源链、取证、成本、兑现年代、三份元数据和真实结果一起验证，不能靠全局tag或一份看似成功的标记触发。
- 原机构的 `annualSource` 保留为历史基底。单一 `getInstitutionEffectiveAnnualSource(state, institution)` 为年度结算与实际展示提供已核实的有效未缩放来源；维护与人手缩放仍由原结算规则负责。它不接受脱离当前state的伪造机构对象。
- 取消不生效，停运或维护归零不产生轮值贡献。授权历史仍可留存；已签事实和当前能否工作分开。
- 合法自定义年度来源不套默认值，不按固定差值减出负数，也不让整局损坏。新版对此明确不提供固定排班合同，仍可继续原机构运作或选择新培训。已经签署固定排班后，篡改对应基底或元数据则拒绝存档与结算。
- 未知版本、无对应合同、错目标、前置成功grant、缺兑现记录及偷改向量都应拒绝；新字段不能塞入旧合同、其他事件、机构或草稿来伪造效果。

## 验证入口

- `node --test tests/training-workload.test.js`：来源重排、真实兑现、维护缩放、取消/停运、自定义基底、元数据负控与隐藏字段读取负控。
- `node --test tests/training-authorization.test.js tests/training-choice-comparison.test.js`：原授权与比较行为回归。
- `node scripts/round21-training-choice-balance.mjs`：自然644组、合成维护边界与真实第20轮生产者12种恢复续跑，旧档逐年完整state对等。
- 独立QA另冻结实际旧生产者及其传递依赖，覆盖更多路线、恢复阶段、叙事和展示；最终全量测试与浏览器证据以本轮测试记录为准。
