# 实现与自评 · v0.1

## 架构

Phaser 3负责地图和相机，DOM负责中文阅读与操作。`simulation.js`独立于浏览器，唯一拥有世界规则；`main.js`拥有UI；新局调查记录由`simulation.js`持久化；`board.js`只读状态并发出选择。Vite打包，不需要运行服务器账户或数据库。

### 原子提交

锁定仅写入drafts，预览不创建世界事件。提交先验证全部棋子、证据、资源和同格冲突，通过后一次写入成本和事件。未定义的同格协作会明确拒绝，不靠点击顺序猜测。每窗记录在committedWindows，不可再次提交。随机按种子/稳定事件ID/条件版本取样，不依赖遍历顺序。

### 年度演化

固定的到期事件与维护时点先兑现，随后所有64格基于同一临时快照计算局部留存、邻接、载体远距传播、特定跨通道收益及持续源，再同步更新。危机冲击发生在第23年当期计算前；这是明确的原型时序选择，未声称完全等同交接方程。无同年递归事件链。

### 治理与覆盖

实际运转的当地制度提供覆盖，开放、维护和人手影响系数；治理来源必须追溯到成功行动。第23年按各地覆盖、来源保护、复核/停闸与当地互助结算，并冻结逐地明细。结局区分当前服务和历史损失，旧存档缺失的历史明细不会补造。数值、公式与兼容边界见[本轮假设说明](GOVERNANCE_ASSUMPTIONS.md)。

### 交互状态

世界页同屏更新复用Phaser Canvas，拖动中心与重绘分离；切换到文字页面释放地图，回来时恢复会话内镜头。显式聚焦或坐标目录定位仍会重新对准目标。DOM更新恢复对应控件焦点，取证按钮消失时把焦点移到已展开材料标题。主行动置于世界页顶部且仅有一个，按真实阶段、地域和角色选择合法操作。

## 自评与下一轮

### 叙事

已实现四个时间窗口的具体角色对话、继任代价及不替他人决定人生的旧档冲突。失败、不建站、重建与停运已分别适配现场、取证和服务选项。风险：同伴目前共享部分场景文案，独立立场可以加强。

### 玩法

第10年续约、招募、夜校、档案与互助争夺单一名额；第20年双棋子要在危机、预警、人际关系、学校等机会间安排。确定性失败能继续游戏。三种治理的开放门槛与来源保护已进入当地覆盖、逐地危机损失和结局；数值明确标为本轮原型假设。风险：建站方向仍共享教学链，未完成独立角色关系和收费账本；取证已按角色跨地点共用三轮，异常与路线占两轮；真实玩家是否能理解机会成本仍需试玩。

### 美术与界面

真实2:1地理、正确锚点、可聚焦/平移、清晰中文、原创档案室。工程代理建筑尚未升级成正式资产。已对代表状态截图审读，不把概念稿当实际运行证据。

### 风险收益

短期成功率、成本和长期维护分别显示；失败成本不返还，失败留档案并有第10年修复；招募增加下一窗行动；存在实际岗位时才有继任或停运代价，无岗位不虚构损失。危机有14→20→23保护窗口。结局依赖已有网络、信任、复核与灾难记录。尚未做真人平衡测试，不能声称某条路径最优。
