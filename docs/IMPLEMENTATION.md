# 实现与自评 · v0.1

## 架构

Phaser 3负责地图和相机，DOM负责中文阅读与操作。`simulation.js`独立于浏览器，唯一拥有世界规则；`main.js`拥有UI；新局调查记录由`simulation.js`持久化；`board.js`只读状态并发出选择。Vite打包，不需要运行服务器账户或数据库。

### 原子提交

锁定仅写入drafts，预览不创建世界事件。提交先验证全部棋子、证据、资源和同格冲突，通过后一次写入成本和事件。未定义的同格协作会明确拒绝，不靠点击顺序猜测。每窗记录在committedWindows，不可再次提交。随机按种子/稳定事件ID/条件版本取样，不依赖遍历顺序。

### 年度演化

固定的到期事件与维护时点先兑现，随后所有64格基于同一临时快照计算局部留存、邻接、载体远距传播、特定跨通道收益及持续源，再同步更新。危机冲击发生在第23年当期计算前；这是明确的原型时序选择，未声称完全等同交接方程。无同年递归事件链。

### 治理与覆盖

实际运转的当地制度提供覆盖，开放、维护和人手影响系数；治理来源必须追溯到成功行动。第23年按各地覆盖、来源保护、复核/停闸与当地互助结算，并冻结逐地明细。结局区分当前服务和历史损失，旧存档缺失的历史明细不会补造。数值、公式与兼容边界见[本轮假设说明](GOVERNANCE_ASSUMPTIONS.md)。

### 交互状态

世界页同屏更新复用Phaser Canvas，拖动中心与重绘分离；切换到文字页面释放地图，回来时恢复会话内镜头。显式聚焦或坐标目录定位仍会重新对准目标。DOM更新恢复对应控件焦点，取证按钮消失时把焦点移到已展开材料标题。主行动置于世界页顶部且仅有一个，按真实阶段、地域和角色选择合法操作。

## 自评与下一轮

### 叙事

已实现四个时间窗口的具体角色对话、继任代价及不替他人决定人生的旧档冲突。失败、不建站、重建与停运已分别适配现场、取证和服务选项。风险：同伴目前共享部分场景文案，独立立场可以加强。

### 玩法

第10年续约、招募、夜校、档案与互助争夺单一名额；第20年双棋子要在危机、预警、人际关系、学校等机会间安排。确定性失败能继续游戏。三种治理的开放门槛与来源保护已进入当地覆盖、逐地危机损失和结局；数值明确标为本轮原型假设。风险：建站方向仍共享教学链，未完成独立角色关系和收费账本；取证已按角色跨地点共用三轮，异常与路线占两轮；真实玩家是否能理解机会成本仍需试玩。

### 美术与界面

真实2:1地理、正确锚点、可聚焦/平移、清晰中文、原创档案室。工程代理建筑尚未升级成正式资产。已对代表状态截图审读，不把概念稿当实际运行证据。

### 风险收益

短期成功率、成本和长期维护分别显示；失败成本不返还，失败留档案并有第10年修复；招募增加下一窗行动；存在实际岗位时才有继任或停运代价，无岗位不虚构损失。危机有14→20→23保护窗口。结局依赖已有网络、信任、复核与灾难记录。尚未做真人平衡测试，不能声称某条路径最优。

可达性仅指取证条件，不替代支付、名额、同格冲突或整轮核对。已经不可达的路线不算本次调查的新增损失；强化停闸不可达也不等于基本停闸消失。自然路线、旧档与独立实际调查对照见本轮最终测试记录。晚期授权/扩建平衡和结局艺术仍是明确记录的下一步评估点，不以本轮信息改善宣称已经解决。

- `training-choice-comparison.js`读取两份真实E4合同、原培训点、当前承接与覆盖；`training-choice-comparison-view.js`默认收起，现有行动卡仍是唯一执行入口。学校年度来源通过模拟模块新增纯读取导出取得，不再在UI维护第二套产出常量。没有新增费用、概率、维护规则或存档字段。
- 644组自然对照与维护敏感性研究说明本轮为何不以人为收费制造稀缺。公开比较不读调查会话、草案、随机数、未来快照或材料正文；条件只表示当前其他状态维持不变时该合同兑现的影响，不代表未来保证或全局最优。
- `ending-recollection.js`在真正第40年结束后，把两名角色最后的真实工作、个人经历和一次第23年历史说明组织为阅读层。默认`characterEpilogue`保留原输出，新可选开关只避免展示层重复部署回顾。来源沿整条祖先链核对，跨表重号、未来、错误现实或循环均不能充当可点击的成功依据。
- `ending-art.js`和9张原创静物只画可核实的文书与物件，不推定人物现职。新导语在图前，人物首段可见，详细经历与全部原评语/技术清点由真实summary展开。对旧概括评语与准确缺项的区别作明确说明，不回写历史。
- 从结局查看来源或现场时，瞬时导航上下文保留原展开状态、位置与准确控件，重复sourceId用区域与序号区分。它不进入世界状态和存档；刷新后继续原trace/visit路径，新导入的世界不能继承旧返回上下文。
- 旧浏览器内容回归通过`readEndingDetails`真实点击新增阅读控件后检查原有文字和来源；本轮独立浏览器专项另从全部默认关闭开始验收新首屏与键盘阅读，避免用回归辅助函数掩盖新体验。

## 第二十一轮：原点职责改排与新校扩容

- `training-workload.js`定义显式前瞻规则和固定排班来源。只有新建游戏保存`trainingWorkloadRulesVersion`；导入与恢复不补标签。来源明确且标准原培训点的新协商，冻结原目标、原年度基底和改排向量，动作、事件、兑现与授权互相核对。合法自定义来源不被覆盖，也不因此判整个存档损坏。
- `getInstitutionEffectiveAnnualSource`成为本轮年度结算与公开展示的共同读取接口。原`annualSource`留作基底，只有真实成功的新合同在原点运转时改变有效来源；维护照常缩放。没有新增机构、覆盖、校验、信任或D5授权，没有改写第23年或旧合同。
- 原点候选来源由0.1/0.25/0.7/0.1改为0.5/0.45/0.1/0.1，顺序为政治/经济/科学/宗教；新校维持原新增来源。它们是独立通道的模型系数，不是可加总的工时或钱袋。自然路线需检验真实年度差值，不能只用文字声称取舍。
- 比较移到E4行动按钮之前，手机逐项对照双方的源项变化，科学负值与收益同层。原点按当前维护、新学校按足额维护分别说明；主角选择的方针互斥明确展示。原点当前→条件来源与详细边界仍可主动展开，不读取未来状态或未读证词。
- 免费场景只留下人物处境、工作取舍和兑现风险，完整数值在免费比较/合同中公开。付费证词保留学徒对职责边界的表达；真实回顾与末页只从核实的新合同回收改排，取消、停运与未知各自保留。
- 真实第20轮生产者及所有传递依赖冻结在测试fixture，兼容测试从旧引擎实际产生阶段档并逐年比对完整JSON，不以删除当前新局标签代替。旧factory测试显式新增新规则身份；旧第20轮自然审计改用冻结生产者，保留其历史结论。旧浏览器断言保留基底、身份和资格检查，另补新有效来源，未降低像素容差。

## 第二十二轮：决策阅读与角色机会成本

- 方案预览、锁定审阅、整轮提交和年度兑现分开表述。草稿目标不再称作结果，提交不声称立即经过十年。

- 不增加规则版本、不改变模拟源码或旧档历史。真实第21与第20生产者继续用于逐年完整状态兼容验证。

## 第23轮：记载、停留与下一次选择

- 视觉：年度首屏去掉巨大重复年份，真实结果与清点正文先于推进按钮；短标题、状态文字和不同轮廓的静态记号共同标明类别，颜色不单独承担意义。十年回顾把实际转折放在统计和进入窗口之前。原文不截断、不缩字号，超长大字页仍需滚动。
- 玩法风险收益：新增按真实逐年结算推进至下一条记载；自动播放遇新增结果、预警、维护、清点等记录即停。保留玩家主动选择的整十年快进，概率、随机轨迹、费用和收益不因播放方式改变。读来源与回访停止计时并可原处返回，不以新数值掩盖阅读问题。
- 叙事结构：主层只复述已经保存的记录，预警不是损失，兑现不是永久维护，失败/取消不改写成成果。保留旧原文的已知纠正说明，缺页与类别未知明确展示，不替人物补同意，也不从未来事件补结果。
- 兼容与限制：新增纯展示模块，不新增存档字段或规则版本。真实上一版与更早生产者的年度世界用于独立对照；来源返回上下文只在当前页面会话内存在，刷新后不伪称仍能返回旧位置。未实现高级回溯、更多完整AVG或真人平衡验证。

## 第24轮：取证之前的跨地选择

- 玩法风险收益：`investigation-cross-location.js`从当前角色实际库存与真实可用合同推导一次调查后新关闭的异地取证路线，不修改或克隆一个假想世界。已有材料、无力支付本次轮数和此前已不可达的方案不归因于本次；可携材料在目的地抵扣，本地同名材料不抵扣。强化与基本停闸分开，另一角色独立。资料异常明确未知，不用空表伪装安全。

- 兼容：此前生产源码只有`main.js`与`style.css`改变，新增三个纯展示模块。模拟、存档、所有既有合同提供器与故事源码逐字保留。旧场景预算不使用现代跨地推算；真实旧生产者和自然路线继续完整世界对照。
