# 第31轮：读过来路，还能回到眼前的人

## 开工与实际体验

远程 main 为 `7107021064d045cb27bec59d8e2e4df081335a85`，树为 `4910c35a0d484dc968c46dc8bffc5a173968c881`。工作区1256个发布文件逐字节匹配后另存隔离基线，没有用旧Git索引覆盖已发布文件。原2805项单测全部通过；这一结果仅是开工基线。

三方面独立体验发现同一阅读断点：在现场核对林澈的入局承诺、迁任关系或回访卡片来源后，只剩“返回档案”。世界和经费并未改变，但玩家失去原来的说话者、卡片、展开材料和阅读位置。真实旧producer也能复现，不能靠只检查新局解决。

另有两处独立实证：手机“回读现场”聚焦标题，却把紧邻的说话者滚出视口；林澈拒绝卡只显示通用立场，已有可信的三种入局经过未在现场展示。结束态从结局回访退出世界后，旧结局返回仍残留，也会占用下一次独立回访的回程。

## 玩法与风险收益

来源往返是免费的核对，不是调查奖励、重新发放预算或新承诺。新的临时起点记住原角色、地域、方案预览上下文、已展开材料、焦点与滚动位置；不改调查库存，不锁定任务，不提交、不推进年份。来源子链和其中的现场回访仍能回到最初的现场。

原调查目的书签和合同预览回程可以接回，已花的轮次不退。旧版调查保存在ui.sessions，所以同时检查旧世界、自动存档和完整旧调查会话，不能只用world不变来宣称旧调查兼容。正常离开、刷新、导入与新局不复活临时起点。已有年度记载、十年回顾和结局回程不被新现场起点抢占。

同一次多击序列不能在页面跳转后误触落到原坐标下的另一控件；正常下一次单击或键盘操作仍可立即执行，不以固定延时掩盖问题。费用、概率、条件、角色名额与原始年度结算保持不变，完整条件矩阵与自然风险收益对照仍需重跑。

## 视觉艺术

现场读头把原说话者和原标题放在同一个有细线与边角区分的区域。返回故事仍聚焦真正的h1，滚动目标包含声部；保留标题语义和完整文字，不以缩小200%字号、截断或折叠故事换取首屏。故事末尾提供免费回看方案的出口。

来源页用克制的回程栏标明原角色、地点、当时年份与从现场打开的原来源。优先展示真实返回按钮，不把整张长卡宣称为手机首屏可见。原场景素材和所有故事正文保留；没有新增虚构图像、自动成功印章或靠颜色独立传意的状态。

## 叙事内容与结构

“为什么这样说”与“现在还能选择什么”接成可往返的阅读，不要求玩家从档案重找人物。拒绝理由直接引用现有核验后的reason，区分安排继任、留下岗位缺口与没有岗位可交接；不替苏岚新增同意，也不把同行或过去的同意说成未来的通行证。

来源元数据只给唯一、当前现实、已经发生的原题与原年份，不读抽签、未来快照或调查库存。嵌套追溯时明确写“从现场打开的来源”，避免把起点标题冒充眼前来源链标题。不可靠来源只缺省元数据，不补写历史，也不让玩家失去返回导航。

## 验证边界

最终结果见本轮冻结记录和独立QA。浏览器自然0—40路线与通过真实文件导入的旧路线分别记载，不混称。最初脚本比对在输入前取滚动快照出现28px差异，诊断与独立QA随后增加只读激活事件捕获，以实际点击时的原处为准；未放宽滚动误差、删除检查或据此宣称测出自然发生率。

物理真机、屏幕阅读器和真人平衡不在本轮认证范围。开发中探索与源文件更新期间的运行保留，但不拼接为最终完整回归。
