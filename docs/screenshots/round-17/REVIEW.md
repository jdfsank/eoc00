# 第17轮：调查前条件比较的独立三轴复核

## 结论与验证范围

- Chromium 真实点击测试 **100/100 通过**，页面脚本错误与资源加载错误均为0。
- 独立引擎审计 **16/16 通过**，不代替其他单元测试或全量回归。
- 主线不是直接注入已调查草案：从新局种子12实际点击“第0年放弃 → 第10年自愿同行 → 第20年林澈在D4取居民证词并锁定居民传讯 → 主角到B4”。主角未取证、还余3轮时先看到比较，然后实际调查异常记录、锁定复核、提交并推进结算。
- 其他数值、旧档与异常状态用明确标记的存档夹具；夹具前史经真实引擎合法行动生成。同格冲突、余额不足和未知待兑现合同是明确构造的边界情境。克隆引擎只作数值与实际结算的对照，不用于代替主线点击。
- 桌面宽1280、移动宽390及宽320/200%字号均测试；这不是实体手机、真人平衡、完整无障碍或读屏认证。

## 一、视觉艺术与信息层级

**本轮有效改进：** 比较区以淡紫虚线、问号及“只读假设”区别于金色行动确认与真实结算。三张等权卡片分别呈现调查、成本、到期年和结果，不把某项涂成“正确答案”。在390px下采用纵向层级；桌面中成本与期限并排，成功和未完成的分支可以直接对照。

**真实像素发现并修复：** 第一版虽然没有页面横向溢出，320px/200%字号仍把 `0.9431` 拆成两行，可能造成数值误读。已反馈并修复为数值不可断行，同时减少大字号下多层内边距；保留完整放大字号，不裁切、不省略。最终截图已人工查看，新增浏览器文本行框断言覆盖每个平均损失数值。

**保留的取舍：** 200%字号下完整比较仍需要较长纵向阅读；预算、未取证状态与实际同伴安排保持可见，四地数学按需展开。没有为了缩短页面隐藏必须在花调查轮次前知道的费用和条件。

## 二、玩法设计与真实规则边界

已确认以下三组既有规则结果，无调参：

- 种子1，B4保档 → 自愿同行：复核80%；成功0，未完成分支0.9431；强化停闸0.1886，基本停闸0.2830。
- 种子12，首轮放弃 → 自愿同行：复核55%；同样的0、0.9431、0.1886、0.2830分支。
- 种子12，联合建站 → 安排继任：复核100%，界面不显示不可能发生的失败分支；强化停闸0.1239，基本停闸0.1859。

每项均与真实取证、锁定合同及第23年逐地结算比对；另以种子0和1分别覆盖实际复核失败与成功。平均算法仍为逐地先四舍五入至四位后再平均。

比较保留林澈的实际安排，不替别人放弃，也不占用主角名额。复核与路线调查各需2轮；实际花掉2轮后只余1轮，替代的2轮方案不可达，界面撤去其整轮结果且真实调查按钮禁用。重读、切换地点、展开、换字号和重载均不退款、不取证、不锁定、不付款，游戏状态及自动存档的游戏状态逐字不变。

缺另一角色安排、同格冲突、无力支付、未知待兑现合同不会被填成完整数值。复核科学余额不足只阻止复核，不掩盖仍可支付的停闸。后查路线不会自动升级已经锁定的基本停闸快照；必须真实重锁。取得路线后也不虚构可新锁的基本版本。

当林澈已在F6锁定唯一一份55%复核、主角只比较B4停闸时，两张停闸卡也明确列出林澈的55%与第22年期限，不把成功分支写成主角的确定能力，也不生成整轮合并概率。已增加独立浏览器夹具和截图。

独立审计还覆盖：深冻结输入、返回对象无别名、读取种子/随机roll/历史正文/未来损失/隐藏材料正文即抛错、同轮培训不回升既有复核概率、双复核不合并概率、重复停闸取最强而不相乘，以及真实旧档的字节不变与原流程保留。

## 三、叙事内容与结构

**本轮有效改进：** 在玩家支付调查时间前，把“记录能否及时送到、闸门能否先停下”放回同一个决定中。标题、边界说明、同伴安排和三个假设方案分层，避免把尚未采取的行动写成已经发生的历史。

复核成功被明确描述为纠正共同指令，零损失系数不等于洪水消失；未完成时保留待核实记录和不退费用，而不是给玩家一个无代价的失败。基本与强化停闸仍然不修正共同标准。界面展示公开材料名称，不泄漏未读正文，也不把本次危机系数写成整个四十年的最优解。

**边界仍清楚：** 新功能只用于新版第20年B4/F6比较。原有“已锁定方案对照”留在整轮核对页面，真实锁定流程仍要求取得证据；旧档保留原合同、原取证及原结算流程。
