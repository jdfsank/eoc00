# 第十二轮：人手规则边界、迁任责任与远港准入

本轮修复的是更早版本就存在的原始旧档续跑差异，不是第十一轮历史阅读引入的新损失。`ef841e8` 原内核仅对测站施加招募缺岗减产/第16年停运；`0a64767` 起把 D4 失败档案站也纳入，却未将人手范围独立版本化。读取快照的功能没有改变当年数值。

## 人手规则与不可识别的来源

- 新局明确保存 `staffingRulesVersion: river-carriers-v1`，仍按现行 D4 测站/档案站缺岗规则，不改变成本、概率、招募事实或第23年公式。
- 支持显式 `station-only-v1` 和 `river-carriers-v1`，显式值优先。未知值在导入或结算写入前拒绝，不替换当前世界或自动存档。
- 没有独立人手字段时，`coverage-v1` 身份采用现行河港范围；原版整体危机身份采用仅测站范围。这个选择是**之后结算的兼容默认政策**，不是判断档案究竟由哪个引擎生产。
- 一个原始旧档可能已在后来引擎下续跑，原字段和事件不足以证明其生产历史。不能根据缺少字段、旗标或通道差值宣称完整回滚、纯旧档或所有未来与原引擎完全相同。
- 不回写任何既有通道、快照、历史、危机、成本或停运状态。已被后来运行时停运的档案站仍停运，不复活、不退款、不补偿。缺字段不自动写入版本标签。
- 原版年16规则保持“第一个活动测站停运”，与年度来源倍率对所有测站生效的范围区分。现行规则的真实招募岗位核验保持不变。

`getInstitutionStaffing` 为机械倍率、地图缺岗与测站近景共用判断。旧档案站不因这条规则减产，不等于林澈从未在那里工作：实际离岗岗位、继任选择和个人身份仍按真实来源保留。维护不足和缺人继续是两个独立原因。

免费方案预览和整轮已锁定卡显示同一条件说明。设置、导入提示与无独立版本的世界卡说明未来政策。原招募兑现文本/ID保留，其旁注明确通用的“减产/停运”措辞本身不能证明某档案站发生过这些结果。

## 迁任的制度后果，不补造人事经过

现有迁任合同会在第21年停用 D4 当时已有的制度，并在 E4 建立标准学校。这一既定机制不是先判断苏岚为唯一维护者，再因为她离开而停站。本轮不改这项已披露的代价。

`relocation-history.js` 在选择前与兑现旁明确合同范围，核验实际行动、事件、兑现、机构创建和续约/重建背景。林澈留下的续约路线与匿名维护小组路线不能被改写成“苏岚独力维护”。已停运机构不能被算作一次新的停运。

原记录未交代撤资、解散、人员调动或具体维护中断过程，因此仍标为未知，不给旧档倒填动机。原文、ID和所有数值保留。第30年回访也保留这份责任；后来恢复不抹除过去。

## 远港收费与公开是现存准入状态

F6近景和地图道具按照原分站真实 `open` 字段区分低横杆/票牌与竖起的横杆/公开告示。它们与分站运行/停运、失败底稿、待核工单和校验桌独立组合，共34套原生矢量状态，不是34段新剧情。

锁定和待兑现的公开协商仍显示原收费入口；第31年真正兑现才开放。取消保持旧入口。停运时封窗封口，准入牌只作为历史规则留下，不暗示仍在提供服务。新美术不改变覆盖、产出、原失败记录或第23年清点。
