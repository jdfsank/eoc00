## 治理差异与兼容回归

- 新模型由实际制度、开放程度、维护与人手产生当地覆盖；成功的官署/联合来源提供有限保护，失败标记不能冒充成功制度。三种成功治理路线产生不同的逐地危机损失和可见结局数据。
- 公开续约真正打开商会测站。免费预警复站补足接班人手；没有测站时建立真实传讯队。南岸互助仅减轻D5直接损失。完整复核、停闸、来源停运、远港继续运行和相同快照/读档确定性均有回归。
- 第23年覆盖与损失冻结，之后扩校只改变当前服务；结局分别展示两者。
- 新开局保存危机规则版本；缺版本的真实旧存档继续原整体公式。测试夹具是提交`ef841e89f06fb221f4a4fc95b65636ce434c5cc5`的原`simulation.js`，只改JSON相对导入路径，直接执行生成旧档，不用删除新版字段伪造旧格式。
- 真实旧版无建站→免费预警第21年导入，继续到23年保留0.8损失，棋盘通道逐格与旧内核一致；旧互助与停闸保留原全局组合。旧版已结算危机和历史记录保持不变。
- 旧版缺继任→成功免费预警复站，在证据齐备时修复继任标记；没有兑现事件、失败事件或停运站不会被自动修复。后来的强制迁任使信任为假，早先续约不会覆盖它。
- 详细公式、设计依据、假设标签和兼容范围见[治理与覆盖假设](GOVERNANCE_ASSUMPTIONS.md)。未实现人口分层、收费账本和独立好感系统；没有声称平衡已经验证。
