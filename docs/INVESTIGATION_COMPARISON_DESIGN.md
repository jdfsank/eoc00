# 调查前条件比较：第16轮设计评估，第17轮已实现

本文件保留第16轮对信息时机问题的诊断与最初设计。第17轮已据此实现只读比较；现行接口、取证边界、共享计算与验证结果见 [INVESTIGATION_COMPARISON_ASSUMPTIONS.md](INVESTIGATION_COMPARISON_ASSUMPTIONS.md)。原例中的概率、费用和锁定条件未调整。

最终界面名称为“调查前条件比较 · 只读假设”，说明“条件推算，不代替取证”。仅在 `planningRulesVersion=tradeoffs-v1`、`crisisRulesVersion=coverage-v1` 的第20年 planning 窗口，于 B4/F6 显示。原整体危机或原场景调查规则的旧档保持原流程；符合这两项规则但早于 aftermath 的旧档保留自身人手与互助规则，并以真实结算验证一致。

## 已复现的信息时机问题

完整合同可免费阅读，但真实整轮风险对照只在所有角色的取证与安排齐备时生成。玩家可能先花2轮查异常，才能看到复核失败的整轮后果；此时只余1轮，不能再花2轮核实撤离路线。这不是免费合同错误，也不是应当退款或补证据的理由，而是比较信息出现过晚。

在第20年林澈已经锁定D4居民传讯、主角尚未调查的真实路线中：

- 种子1，B4保档→自愿同行：复核80%，成功损失0、失败平均0.9431；强化停闸0.1886，基本停闸0.2830。
- 种子12，首轮放弃→自愿同行：损失分支相同，复核概率55%。
- 种子12，联合建站→安排继任：复核100%，不应显示不可能的失败分支；强化停闸0.1239，基本停闸0.1859。

这些数值来自现有规则的合法取证、锁定和结算对照，不是新设平衡参数。复核与强化停闸各需2轮调查；基本停闸无需调查。复核花经济4、科学3，停闸花政治4，不能仅凭洪水系数宣称哪个是整个游戏的最优选择。平均值必须沿用逐地先取整再求平均的现行算法。

## 最初提出的最小界面

独立命名为“调查前条件比较 · 尚未取证”，明确保留另一角色已经锁定的实际安排，只在假设主角分别选择三种方案时显示条件分支。各行列出调查需用/剩余轮数、行动成本、到期年、概率及成功/失败后果。已花调查不退；只剩1轮而仍缺两轮调查的方案标为不可达。

不得改变真实“已锁定方案对照”，不得新增可提交的伪草案、取得材料、锁定权限或证据快照。只能使用已公开的材料名称与合同条款，不能泄露未读正文。其他角色未安排、同格冲突、余额不足、行动不可用或存在无法解释的待兑现合同，不给整轮数值，不自动把别人当作放弃。最小范围只覆盖新版第20年规则，旧档保持原流程。

## 实现前提出、现已覆盖的边界

现有 `getCrisisOutlook → getWindowReview → validateState` 会读取种子做结构校验。严格不读取种子/随机结果的假设比较不能直接复制整局后调用它，更不能伪造调查并调用lock/commit。应先抽取共享的公开规划检查与原有投影数学，由真实草案对照和假设对照分别提供事实；真实取证边界不得增加“忽略证据”开关。

建议独立API `getInvestigationComparison` 返回明确的 hypothetical 展示数据，不返回可提交草案。需要深冻结、隐藏字段抛错getter、返回值无别名、预算/草案/存档逐字不变，以及与真实逐地结算的对照测试。调查后未重锁仍用原快照；同轮培训不提高既有复核准备；双复核不擅自合并概率，重复停闸不相乘。未知状态保留未知，不以简化模型填数。
