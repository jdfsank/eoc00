# 第四十年的河岸末页

## 已实现的视觉与阅读改动

结局不再沿用所有路线相同的档案桌。新的横幅把账册的折页接向河岸，沿用项目的深河青、苔绿、旧纸、暖金和平面几何。旧册、磨损水尺、签署页、另置的教学工具、卷回合同和未展开套页分别承载不同的已存事实；没有人物肖像、外部图片、具名现职或人数统计。

`src/ending-art.js` 只在第40年已结束时读取已兑现记录，不读随机数、草稿或未来结果。原学徒授权由现有严格来源接口核对；新培训需行动、事件、兑现页、年份、现实与角色身份一致。缺页或来源不一致不补画成果。授权页与当前培训运行状态分别处理：后来停运保留签署，但束起工具；新培训后来停运也保留记录。取消卷宗、未签页与未知套页有不同形状，不依赖颜色。

9张原创1000×420 SVG位于`public/assets/ending-*.svg`，由 `node scripts/render-ending-art.mjs` 重生成。场景是记录的静物示意，不是对实际建筑、工具、人数或人物在场的写实断言。图注与可展开的来源同时提供文字解释。既有`sceneArt(...,{ending:true})`兼容接口保持原样；新终局页面直接调用新helper，不改旧存档世界或历史。

## 阅读顺序与来源

- 合并重复的年号栏，让本局简短收束先于装饰图出现。200%仍把根字号从16px变为32px，没有固定像素缩字规避大字。
- 先读最后两名角色实际提交及兑现的工作，再读林澈、苏岚的个人末页。人物首段始终展开，其余故事用原生details承接，不把整个人物隐藏。
- 完整旧结局评语、所有条件段、复核清点、指标和原人物全文保存在显式“核对这份结局”账册中。旧评语可能使用概括措辞时，新说明明确区分原文与本页逐项核对，不重写存档历史。
- 来源链接显示真实年份与事件标题。来源及现场回访可回到结局原处，恢复所有嵌套折叠、同名来源的精确按钮焦点和滚动位置。上下文仅为本页面进程内的导航状态，不写入存档；刷新会丢弃这一返回捷径，原档案/世界导航仍可用。
- 第30年E4新增公开取舍比较，默认紧凑收起，在两行动卡后、实际取证前。展开后显示真实成本、授权对象、年度来源与条件覆盖；不能把未来来源当作确定净增，也不能把同地多校当作多地域。
