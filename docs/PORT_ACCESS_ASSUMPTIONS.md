# 第九轮：远港开放、关系回应与居民钟报

以已发布dab5debe为基线。本轮补足三项可玩体验：最后十年仍有办法协商远港的收费门槛；林澈记得主角是否替苏岚作了决定；无测站的居民传讯有自己的近景。远港行动是新增的原型设计，不是把未验证设定冒充原交接规格。

## 新局限定的远港合同

`port-access-v1`只随新局建立。第30年F6必须存在真实来源、仍有效运转且未公开的branch，才可选择`open_port_warning`。失败底稿、独立复核站、停运分站或空河岸不能充当目标。

假设成本为本地经济4、政治2、该角色一轮当地居民证词调查和一个介入名额。成本尚未经过真人平衡验证。居民证词不可借另一角色、另一地域的调查替代。与E4培训、F6遗留校验或交班方针的名额竞争才是主要机会成本，不靠新加随机灾害惩罚未建站路线。

- 锁定只保存草案，不支付、不开放，也不提前创造机构。
- 整轮提交核对真实目标，冻结`portBranchIds`、来源与证据，一次付费。
- 第31年逐一核对冻结目标仍在有效运转且尚未公开。条件齐备，只把原分站`open`改为true；原ID、年度产出、来源、维护与其他机构不变。
- 目标身份还在但停运、维护为0或已经公开时，整项取消，费用不退。移除来源身份、换成另一机构或伪造证词是坏档，而不是可替代目标。
- 不增加教学人手、异源校验、地方授权、河港信任或方针，不重开停运载体，不补维护，也不改第23年结算或原复核成败。

足额维护的分站收费覆盖0.45、公开覆盖1，实际仍乘原维护系数。这里描述当前制度的覆盖，不承诺尚未模拟的下一场洪水损失。第30年整轮对照承认这份服务合同，但承接指标不因此加分；31年取消条件单独说明。

这不是强迫每个结局都公开远港。玩家可以选择先补交班能力，也可以把名额用于眼前服务。已有充分准备时，两者可以兼顾；准备不足时，一次声明不能同时补齐人手、校验和开放。

## 合同与旧档边界

新合同检查规范行动ID、执行者、地点、30→31年、原branch完整建站/培训/分站来源、冻结目标列表、已实际调查的当地/可携带证据，以及对应兑现记录。协调改名、调包目标、删除事件、删来源、乱改年代或伪造成功均在导入/推进前拒绝。第31年成功须确实已开放；后来合法状态中的停运不抹掉曾经兑现的历史。

真实dab5debe模拟源码保存为`tests/fixtures/pre-port-access-simulation.js`，唯一变化是JSON导入路径。原Git blob为`34ec88cb44e1df40b46f97a501c16fc32248d60c`。旧局不获得新菜单、不添加版本标记、不改原合同或计分。新场景与对照是只读解释，不改旧局未来状态。旧F6场景同样不暗示它能选择本轮新增的协商合同；失败底稿的后续校验仍按原版本提供。

## 林澈会记得关系中的选择

第30年东岸现场与第40年尾声新增只读回应。她的同行约定不被写成自动认可强制迁任，也不触发退队、惩罚、信任加减或自动原谅。尊重苏岚的真实选择也不成为以后替她签字的通行证。

回应只读真实入局记录与20→21年的迁任/尊重来源；标记本身、错误执行者、异常年代、缺失兑现或不一致父项都不能补写指责。真旧局若由林澈本人执行迁任，文案承担她自己的责任，不倒算成主角作出的命令。原11/16年交接责任、她自己的20/30年贡献及23年历史继续保留。明确放弃的路线不被补写成参与测量或带教；旧局没有完成复核时也不虚构后来的成果。尊重的对白不把林澈亲自呈档的选择归功于主角。

## 居民钟报不是一座测站

D4没有station而有真实warning时，使用运行、维护不足、停运三张原创近景。保留原档案架和旧记录，门外为低钟架、轮值板与传讯人员，不画水尺塔；停运保留钟架并系绳封板。真实station仍优先原测站状态图，失败档案不会因传讯出现而被说成重新开站。
