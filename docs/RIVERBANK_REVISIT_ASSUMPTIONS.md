# 第十八轮：在河港与东岸回看真正留下的事

## 真实的阅读缺口

既有只读回访覆盖B4、D5与F6，D4和E4的场景却依赖有可用行动的介入窗口。迁任与教学在第21年兑现、最终方针与后续教学在第31年兑现后，玩家能够查档，却不能直接回到这两处场景观察服务与人物决定的后果；第40年结局也没有这两地的回访入口。

本轮为D4、E4增加独立只读回访。规划现场仍保留有限取证与每人每十年一次介入的规则。回访不调用规划剧情，不开启调查，不获得材料，不锁定、不支付、不提交、不推进年份，不改变人物、制度、概率、历史或结局。

## 当前服务、已经发生的事与未兑现合同分别阅读

- 当前场景只表达已经存在的本地载体。测站的运行、维护、缺岗与收费准入分开叙述；档案保管不能冒充预警，居民传讯不能冒充测站，也不能恢复旧档案岗位。
- 东岸把原学徒培训、夜校、轮值维护教学与迁任学校的来源逐项列出。多所机构可以共存，一所停运不抹去另一所的教学。未来日期的机构不提前出现，缺失的运行字段保持未知。
- 草案不产生回访变化。只有已提交、记录了实际成本、日期和原始行动的合同才显示“待兑现”。待办没有完成来源，不把预定结果画成当前建筑、到任或签名。
- 兑现来源必须连接规范行动、合法执行者、已付成本、所需材料、对应事件、实际结果与正确地域。字段互相矛盾、重复ID、跨表冲突或缺页都不能补写成功。链接只指向已有历史页，完整父链必须属于已经发生的当前现实。
- 第23年清点独立展示。当前学校、恢复服务、后来的授权与结局不重算旧损失，不从建筑外观推断伤亡或毁损。旧版只有整体结算时，分区细节仍未知。

## 两岸的人不是同一份机构表

林澈入局、苏岚同意原继任合同、尊重当前意愿与迁任，分别引用真实行动与兑现记录。匿名重建或教学机构不能给任何人补上岗位。过去接班不证明今天仍在职，合作不等于永久同意，后来的成功不代表原谅。

迁任的原行动和结果仍归D4。E4只引用河港原件与实际目的地学校，不复制出一条东岸迁任事件。D4说明合同的制度停用范围，不把停运归咎于苏岚个人能力，也不补写撤资、解散团队或其他人的调动。个人反对仅引用原结果中实际保留的证词；缺少证词时不补写她的态度。

## 原学徒的承接签名

新规则下的第30年E4方案由独立的训练授权规则定义。读回接口消费该规则的纯来源接口，不重新实现其结算。剧情让玩家比较“新增一组教学”与“和既有原学徒协商承接责任”，而不是把已有人员再次培训视为唯一出路。

政治3、经济2支付会议、公开轮值和记录工作，不购买同意。E4居民证词记录原学徒提出的公开记录、拒绝不安全指令与有限责任条件。读到条件只是取证，仍须提交合同，并由第31年仍符合条件的原学徒留下签名；主角与林澈不能替他们签署。

回访与十年回顾分别说明已付待办、真实授权、因目标失效或已有授权而取消、以及来源未知。成功仅属于冻结的原E4学徒目标，不新增学校、人手、产出、预警覆盖、校验、河港信任或终局方针。取消不退已付成本。后来停运仍保留原签名，但不能写成今天仍在带教。旧局不补发新方案或授权。

## 验证边界

核心测试包括自然推进的21/31/40年、草案与待办区别、真实停运与恢复、匿名教学、原地域来源、缺页/重复/现实冲突、七种真实旧引擎轨迹、冻结状态、返回值无别名及禁止读取种子、随机值、概率、未公开事件正文和调查库存的getter检查。新授权另覆盖方案条件、成功、取消、晚期停运、破损来源与旧局不迁移。

这是阅读、叙事和可操作方案的具体改进，不是新增人物人生模拟。没有进行真人平衡、真机或屏幕阅读器认证。视觉与浏览器验收由本轮对应报告单独记录。
