# 第31轮：现场来源回程

## 临时状态与边界

main内的现场来源起点仅存在于当前页面会话，不进入存档字段。avg的来源跳转和没有上游阅读起点的直接visit可以建立它；来源链中的trace与visit沿用原起点。年度记载、十年回顾、结局已有的回程保持优先，不能因继续查来源而被覆盖。

返回恢复原角色、地域、choice、details状态、焦点和实际激活时的滚动位置。调查记录不从起点复制，不重新创建或退款。仍有效的取证目的书签和方案预览起点在单次重绘前恢复。离开来源链、刷新、导入、新局后起点消失。结束态的结局起点也在明确离开阅读链时清除，防止未来独立回访误接旧路径。

指针保护只处理已经重排页面的当前多击序列。原生mousedown/click的detail大于1时拦截并保留焦点；新的单次点击与键盘操作即时有效。

## 专项方法

新增功能专项通过真实控件完成build_joint、recruit_successor、present_archive、independent_review、share_power与authorize_training自然路线，四十次年度推进逐一比对引擎生成的完整世界与自动存档。拒绝和尊重关系来源实际跳转、原题原文、子链与回访、原处恢复分别检查。

另从真实pre-tradeoffs生产者生成并通过文件控件导入旧档，在E4实际花费一轮旧现场调查，再核对完整旧ui.sessions、世界和存档。导入样本不是本次自然UI从零路线。中断、刷新和替换存档不保留临时导航来源。

读入页面的事件诊断只监听，不伪造点击或世界。滚动期望取实际激活事件发生时的值，记录输入前与激活时的差异；不接受固定误差或额外延时。最终专项报告与聚合统计以冻结验证为准，独立QA另有更宽分支覆盖。
