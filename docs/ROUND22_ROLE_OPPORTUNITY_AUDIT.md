# 第22轮：把主角的方针名额摆在调查之前

## 发现与范围

本轮先跑自然路线，再改善提交信息，不调整成本、成功率、回报、调查预算或介入次数。第30年只有主角在D4能签署 `share_power`、`central_review`、`withdraw`，林澈不能代签。原先E4现场、授权预览与训练卡没有把这条角色限制作为主层信息显示。整轮交班对照虽写“未锁定方针”，普通训练加同伴放弃的 `getWindowReview().warnings` 仍为空，也不会解释这不是同伴稍后可以补签的工作。

这不是“不签方针就无效”，更不是所有建设都应该放弃。目标是让玩家在花调查轮数和提交之前知道哪个名额被占用，自行决定是否签方针。

## 可重跑的自然证据

运行：`node scripts/round22-role-opportunity-audit.mjs`

输出：`playtest-output/round22-role-opportunity-audit.json`。脚本只调用真实建局、调查、锁定、放弃、统一提交与年度演变API，不修改地方能力、机构、人手、成功概率或种子结果。

固定种子0、1、2、3、12，各比较 `authorize_training` 与 `train_network`，共10组：

1. 第0年D4联合管理。
2. 第10年D4招募林澈并安排继任。
3. 第20年主角B4独立复核，林澈D4免费预警。
4. 第30年分两条支线：主角E4完成该工作、林澈放弃；或林澈E4完成同一工作、主角D4共享方针。

10组中，两条支线都合法提交、建设成功，最终承接人手、地方授权、异源校验、信任及 `canShare` / `canWithdraw` 一致。主角做E4工作的一支全部 `canShare=true` 却 `policy=null`，结局为“未签署的下一页”；另一支签署共享方针，结局为“许多人签署的历史”。5条普通训练支线的引擎警告列表为空。这里对照的是角色名额和方针决策，不声称两支所有资源指标相等。

另有两条自然准备路线：第0年放弃、第10年自愿招募、第20年两人放弃，真实到达没有任何机构的第30年。主角独自筹备B4未来校验时，材料费用经济6、科学4在提交时支付，第34年因无人手取消；同时让林澈培训时，校验第34年成功。后一支仍没有方针，但新增工作是真实有用的合法结果。提示不得把这类两名额准备组合标成错误或强制阻止提交。

以上是10组定向路线及2条准备分支，不是整体平衡、真人试玩或所有策略的认证。

## 最小实现

- `src/planning-opportunity.js` 是只读公共信息模块，提供 `getPlanningOpportunity(state, {actorId, cellId, actionId?})`。省略位置参数时用于整轮安排；现场参数用于调查前；加行动参数用于行动预览和锁定审阅。
- 只在第30年介入窗口，以及当前角色确有行动的现场返回模型。没有行动或其他窗口返回 `null`。
- 明确区分主角尚未安排、已锁方针、已锁其他工作、明确放弃。异常草案另列“待核对”，不能补成已锁方针。
- 已锁状态由 `getLockedPlanningFacts` 的公开有效任务确认，拒绝缺证据、未取得证据、错误地点、过期窗口等不一致草案。不调用整份存档验证，也不读取随机数、种子、快照、未读证词或未来结果。
- `src/planning-opportunity-view.js` 把唯一签署者、实际状态和本次选择的后果直接显示。额外取证/锁定/提交边界放在原生展开项中。不会替玩家锁任务、换角色、退调查轮次或推荐唯一正确的方针。
- 所有成本、时间、取消条件、成功规则及结局判定仍由原引擎负责。模块不新增存档或规则版本字段，不改历史。

视觉接入由本轮主界面改造负责，在每个相关屏幕只显示一次，避免逐任务重复堆叠。主层需要保留两点：林澈不能代签，以及主角的非方针工作/放弃会让本轮不签方针。读者不应被迫先展开完整合同才发现。

## 测试与旧档

运行：`node --test tests/planning-opportunity.test.js`，9项通过：

- 四种真实角色状态、所有第30年可行动地点与合法行动上下文。
- 预览另一个行动不改变已锁草案，跨角色阅读不虚构已签方针。
- 深冻结世界后重复渲染，世界、证据、成本、历史、规则与草案字节不变。
- 用会抛错的属性拦截种子、随机结果、快照、基线和材料叙述；模块不访问它们。
- 过期/伪造/缺证据草案不产生已锁方针结论。
- 两人准备且不签方针仍可真实提交、兑现，不增加强制确认或挡板。
- 真正的上一轮生产者和最初版生产者存档读取后不改变字节，后续按各自原规则演变也与未读取对照完全一致。
- 转义角色姓名和文本，核心风险在详情外可见。
