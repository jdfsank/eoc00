## 必须保持的行为边界

1. 免费预览、锁定审阅、折叠详情、返回与导出均不获取证据、不支付介入成本、不推进年份。
2. 调查真实花轮次。解除锁定不会退回已用调查轮次；后来取得撤离路线，不会悄悄把已锁停闸由0.30变成0.20，只有明确重锁才更新合同。
3. 统一提交原子支付成本并进入原年份的 `playback`，第一次逐年推进才进入下一年。同格冲突、未安排角色继续阻止提交且不发生部分支付。
4. 第30年主角在 B4/E4 调查前看到仅自己能在 D4 签方针的限制。林澈的工作不占主角名额；查看另一候选不提前替换已拟方针。两份非方针工作仍是合法选择，不新增强制签署规则。
5. 成本、概率、发生时间、失败/取消与不退费条件默认可见。重复依据可以折叠，但不能靠折叠隐藏必要风险。整轮显示“若合同兑现的目标”，不把锁定称为结果。
6. 真旧生产者保留的 `ui.screen="window"` 可以与已提交或已结束的状态共存。此种持久化 UI 夹具通过首次导航前的存档初始化载入，不篡改运行中的世界。只读恢复页不得再显示未支付、未安排或可修改控件。
