# 第二十轮：让最后的工作得到明确回应

## 先核对真正的问题

本轮从已发布的第19轮继续，不先增加合同或改动经济参数。独立实跑种子0至19、三类建站、两类招募和八种第20年安排，得到644组原学徒授权与新增培训都可选择的自然对照，其中52组包含复核失败。

在这644组中，新增培训第40年的E4四通道都更高，而结局标题、四地覆盖、已发生的危机与承接资格相同。典型自然路线中，新培训的科学在第33年反超、经济在第37年反超。按这些终局指标衡量，新培训占优；这不是对全部合法状态或全部玩家价值目标的最优性证明。

原学徒授权仍有不同的意义：给已有人员协商本地承接权，不是建立另一所学校。此前这一差别没有得到足够的结局回应。主角亲自执行授权或新培训、林澈放弃的两条自然路线，原有完整人物尾声甚至逐字相同。结局常见的概括性失败评语也未准确指出“只缺地方授权”的实际缺口。

## 不用人为收费掩盖问题

当前四通道会向各自基线回归，并不是守恒的钱袋；第30年后也没有新的介入窗口。自然样本中E4的政治、经济、科学远高于两项合同费用。小额年度收费只会改变最终数字，不能让省下的经济获得新的再投资用途。敏感性实验甚至要把年度收费提高到明显超过一次建校费，才会在少数灾难路线末年制造短缺。

因此本轮不新增维护扣费，不宣称修好了数值平衡。合成贫困、原点停运与维护不足仍是有价值的合法边界测试，但不把它们包装成自然玩家路线。

## 三方面一起改善

**视觉：** 结局从同一张档案桌改为有明确物件差异的原创静物。授权页、另置的教学器具、未签页和收起的工具分别对应可核实的记录，不借画面补造人数、具名任职或居民同意。简短导语在画面之前，人物与最后工作优先，完整规则账册在后。

**玩法风险与收益：** 第30年E4在两项真实合同都可选时，公开比较即时投入、调查要求、原有承接者与新增载体、年度来源以及对当地承接与覆盖的实际意义。年度来源不是未来通道净增量；同地多一个载体不是多一个自治地域。授权不会附送校验、信任或方针，新培训也不会替原学徒补签同意。覆盖按当前公开条件核对，不能一概说新培训没有作用：原培训维护不足时，新学校能够补足当地覆盖。

**叙事结构：** 两名角色最后一次真实工作的选择、兑现和留下的责任获得独立回收，不只把同伴工作塞进长尾声。个人经历保持其真实来源，不重复粘贴每段危机说明；第40年不再用“下一次介入”暗示还有未开放的游玩窗口。新收束按实际缺项说明未完成的交班，保留原结局评语和历史原文供核对，不偷偷改写旧记录。

## 边界

- 不调整行动费用、概率、调查预算、年度结算、存档版本或已发生的历史。
- 比较读取当前公开规则和条件，不读种子、随机结果、未读正文或未来快照，不代替调查、锁定、支付或统一提交。
- 结局只在实际第40年结束后提供，不把尚未兑现的合同画成成果。
- 已签署不等于今天仍在运转，曾经建成不等于当前岗位已知；缺页不写成拒绝、失败或同意。
- 屏幕阅读器、真实触屏设备和长期真人平衡仍需后续验证。本轮自动化与浏览器截图只能证明列明的程序和展示边界。

最终代码、浏览器与像素验收以本轮测试记录为准；自然对照和维护敏感性仅用于解释设计取舍，不作为完成平衡的认证。
