# 第17轮：调查前条件比较界面

## 信息时机与交互边界

新版第20年B4/F6现场在“现场取证”之前展示“调查前条件比较 · 只读假设”。交叉复核与停闸的免费合同预览也展示相同面板；真正的锁定确认页不重复展示，既有“本轮风险对照”仍只解释实际已锁定安排。

面板只接受 `getInvestigationComparison` 返回的公开展示数据，不读取游戏状态、证据正文或随机结果，不含调查、锁定、提交按钮。展开四地说明只是浏览器原生 `details` 阅读操作，不创建游戏内草案，也不保存新界面规则标记。旧局或不适用的年份/地点由API返回空，保持既有流程。

三项方案分别显示还需调查轮次、调查后的余额、当前地点支付的确定成本、本角色一次介入、到期年与本项概率。已取材料逐项标注，不再把调查后的玩家笼统称为“尚未取证”。预算不足时显示实际缺口，不展示负余额；已有撤离路线后，不能新锁定的基本停闸按API标为不可采用，不改写尚未重锁的旧草案。

其他角色的已锁定任务或明确放弃单列在上方；未安排不是放弃。所有方案共享的阻碍只列一次，方案下保留自己的缺口。不能完整核对公开资料时不补写调查余额；没有可核实合同时不把空字段显示成免费、0%或“第null年”。

## 视觉艺术

沿用游戏低饱和档案纸质感，但使用灰紫墨色、斜线底纹、虚线边框与问号标记，区别于金色承诺/结果卡。三项采用同构的编号卡片，没有胜负颜色、推荐星标或似已完成的勾选。损失数字与其条件同卡展示，零损失始终注明只指共同失效，不是洪水消失。

布局不使用固定宽度表格。费用与时间采用可换行定义列表，分支与地域明细采用可收为单列的网格；320px或200%字体下强制单列。所有状态都有文本，不能只凭颜色区分。原生展开控件沿用现有键盘焦点样式和滚动留白。

## 叙事结构

叙事引句只表达尚未发生的水位、记录与闸门选择，不写出未读取材料的内容，也不假借居民新增发言。角色、地点和已锁定安排均来自公开API。

复核分别说明成功和未及时完成的后果，100%合同不写不可能的本项失败后果。整轮成功/后备分支只根据投影的 `success.available` 与 `fallback.possible` 显示。其他角色已锁定的单次复核也逐项列出概率与期限，不能在停闸比较中隐藏其条件。双复核逐次列出角色、地点、概率与时间，不合成成功率；停闸说明采用较强的一份，不重复相乘。数值保留最多四位小数，末尾零可省略；四地详细条件明确先逐地四舍五入再平均。

这张比较页帮助玩家决定先调查哪份材料，不声称最低危机损失就是整个四十年最优方案，也不返还已花预算或承诺未来结局。
