# 第24轮叙事评审：先看清这一次会放弃什么

## 基线实玩结论

第23轮已经把实际变化、十年回顾、来源和回访接回阅读路径。本轮不重复改结局、年度结算或人物尾声，重点是取证前的选择。

两条真实浏览器路线从空白临时浏览器，通过设置新建 seed0，再用实际地图坐标列表、角色、合同、调查、锁定、统一提交和年度按钮游玩：

- 联合建站 → 安排继任招募 → 主角B4完整复核、林澈D4免费预警 → 主角共享方针、林澈E4原学徒承接 → 第40年。结局确实回收到授权、人手、校验、合作和个人选择；没有必要再加一套结局评分。
- 第0年放弃 → 自愿招募 → 第20年主角在D4阅读旧教师履历1轮，再调查居民证词1轮 → 去B4核对。第二次调查前只显示“本次用1轮→调查后剩余1轮”，没有提示它会使该角色无法补齐B4/F6的复核与强化停闸。调查后两个选项确实不可达，基本停闸仍可用。

人物阅读也有机会成本。玩家可以选择把时间留给苏岚与河港，但应在花掉不可退的轮数前理解自己放弃的其他工作，而不是到另一处才发现。

第20年D4迁任卡的默认文字只谈“短期补充标准教育岗位”和无需取证，关键代价在免费合同里。它不是完全隐藏风险，但在比较层容易把未经本人同意的迁任读成便宜的教育选项。

## 限定的迁任卡改动

`getActionCardTradeoff(action)` 位于独立的 `src/action-card-copy.js`，只接收已经由正常可用行动列表取得的公开合同。

- 只有 `relocate_teacher` 返回两项：“若合同兑现”逐字取 `action.reward`，“仍需承担”逐字取 `action.risk`。
- UI用这两项替换该卡原description，另列“去向与制度范围”，逐字采用既有迁任合同说明中的公开规则和真实目标范围；不重复叠加description，完整合同仍保留原描述。
- 有真实维护制度和无在岗制度的动态句子来自原合同，不能按标题猜测，也不把档案岗位写成测站岗位。
- 不改写苏岚的意见，不宣称她同意迁任，不把制度停用归罪于她个人；不为拒绝亲自执行的林澈补出该选项。
- 每项返回 `field`、`label`、`text`、`known`。缺失、空白或非字符串的字段返回 `known:false`、`text:null`，应显式保持未知，不能借另一字段或description填出事实。
- 有效原句保留完整条件、标点、空白和换行，不截断、不添加省略号、不清洗成新的承诺。
- 其他行动返回null。建站旧档有专门的展示规则；呈示旧档的目标不能被读成已经同意；末期方针也不能只用一句泛化收益替代真实承接条件，因此不全量替换所有卡片。

原 `decision-stage-copy.js` 与第23轮冻结基线逐字一致，旧保护清单不放宽。新增helper不导入模拟、存档或材料模块，不建立新字段。

## 跨地预算提示的叙事边界

1. “这次后无法补齐”只表示这名角色、这一窗口、真实共享调查预算下新关闭的补证路径，不表示另一角色也失去能力，不是全局坏结局判词。
2. 区分本来就不可达与本次才关闭。明确基本停闸与花两轮强化停闸不同；强化不可达不能写成停闸完全消失。
3. 地方证词仍是本地材料。提示跨地机会成本不会使它能在其他地点充证，也不会把一人的材料共享给另一人。
4. 已锁定草案继续使用其真实证据快照，追加或转去别处调查不暗中增强、弱化或替换它。取证不是锁定或统一提交，免费查看也不会退回已经花掉的轮数。
5. 可达性仅按公开合同及实际已得材料、剩余轮数判断，不读取种子、随机抽签、未来快照、未读材料正文或未来结果。不能为了说明机会成本把未读居民意见提前讲出来。
6. 缺页、未知或不适用的旧局维持原语义。原按现场分开的旧调查预算不能被新提示说成跨地点共享。
7. 可以说明“取证不足”，但不能把它扩写成“无人愿意合作”“居民已经拒绝”“这条结局已失败”。没有调查并不是人物没有意见，也不是人物已经同意。

## 现场跳转与返回的阅读原则

现场提供直接去选择、去材料的入口，以及从免费合同返回原卡片或材料位置，能让玩家真正比较而不反复重读全文。它们只负责阅读，不替玩家选行动、花轮数、换人或改变锁定任务。保留实际阶段与目标；新局、导入、刷新后不可冒充仍有旧阅读上下文。此项由主线程实施与验收，本文件不把其设计要求说成已独立通过的浏览器结果。

## 验证与限制

新增 `tests/round24-action-card-copy.test.js` 覆盖：

- 当前版本及两个带原始来源提交与SHA清单的真正旧生产者，各自自然走到第20年；成功测站、未建站、失败后真实档案岗位分别核对。
- 两种岗位状态的六条自然路线继续提交迁任与另一角色复核，再到第40年；每次锁定、提交、每年完整JSON、存档恢复与结局和相应生产者一致。
- 林澈实际拒绝时，真实行动列表没有迁任，展示helper不制造选项。
- 完整拷贝、返回对象脱离原对象、缺失字段保持未知，以及只读取公开id/reward/risk的字段陷阱检查。

该专项不是全套回归，也不替代本轮集成浏览器验收。基线两条浏览器路线无pageerror，证据在仓库外 `../round24-story-audit/`，包括脚本、每屏文本、自然存档与实际视口截图。没有往游戏state或localStorage写入测试世界。390px下四张代表图已逐图查看；320px/真实200%另有捕获，不能把捕获等同全面像素验收。没有真人平衡、真实手机或屏幕阅读器认证。

## 集成后的独立文字复核（探索性）

主线程接入迁任helper与跨地提示后，再用两个新建seed0路线分别自然走到现代第20年的真实测站与未建站状态。通过实际按钮打开D4迁任卡、免费合同并返回；另切换林澈，再由主角读旧履历，展开尚未调查的第二份居民证词。

24项探索性检查通过，无pageerror：

- 两条路线迁任卡的“若合同兑现”和“仍需承担”文字，逐字等于当前公开合同的reward/risk，也逐字等于实际免费合同页相应字段；原description没有重复叠加。后加的“去向与制度范围”另见下方复核。
- 有测站时保留原合同的现存制度维护代价；未建站时保留原合同“不替河港建成测站”的边界，没有凭空画出原岗位。读卡、免费预览和返回前后完整世界JSON不变。
- 林澈D4实际列表仍没有迁任卡，也没有额外的迁任取舍条目。
- 第二份D4居民证词仍未取得。新提示只展示行动名称、地点及轮数，未带出未读居民意见；源代码新增view也没有读取材料正文。
- 提示分别列出B4/F6按真实准备命名的完整或紧急复核，以及强化停闸；明确“只核对这位角色的取证轮数”“不代表方案已经失败”“林澈的调查轮数不受本次影响”。两地都保留“基本停闸仍无需取证”，不将补证不足当成坏结局或居民拒绝。

未发现需要阻断的叙事问题。有一项低优先可读性建议：行动标题与“调查后仍需”之间加标点或视觉分隔，避免连续读成“组织紧急交叉复核调查后……”。不应为变短而删去条件。

## 迁任去向与制度范围补充复核（探索性）

仅展示原reward/risk会使“东岸”去向和合同直接停用制度的后果不够显式。当前迁任卡保留这两项，并新增第三项“去向与制度范围”。该项逐字取既有 `getRelocationContract(state).detail.slice(0,2)`，不是新增合同或人物剧情：

- 第一段是原公开规则：迁往东岸，并按合同停用河港当时已有的制度；停运不以苏岚是否曾担任维护者为条件。它避免把合同后果误说成她个人离开造成。
- 第二段按现有来源区分可核实目标、确无河港制度与来源未知。有目标时不会把已停运制度算作新的停运；无目标时不虚构一次停运；来源不足时不推断没有制度或补写停运过程。
- 没有带入detail中的个人经历段落，没有新增同意，没有把未读材料正文或未来结果提前显示。两项原reward/risk仍逐字保留，没有因说明范围而删短风险。

再次用真实控件从两条新建seed0路线走到第20年有测站/未建站，逐字核对新段与现有公开说明的前两项，并复核原两项、无重复description、林澈拒绝、跨地补证边界和不变世界。32项探索性检查通过，无pageerror；“东岸”“同时停用”与真实有/无目标均在实际卡片上，未包含prior人物经历。未知来源分支已只读核对现有实现，本次没有把合成缺页状态冒充自然UI路线。

证据在仓库外 `../round24-story-audit/integration-scope.mjs` 与 `integration-scope/report.json`；有/无测站两张迁任卡390px实际视口图已实看。本段确认文字来源与语义，不代替最终样式、320/200%或正式QA验收。
