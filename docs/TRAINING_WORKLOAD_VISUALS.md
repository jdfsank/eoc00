# 第21轮：先看真实取舍，再进入合同

## 这轮展示改了什么

E4原学徒授权与新培训的比较现在位于免费行动按钮之前，跟随当前调查预算和地点提问。比较与按钮统一为“原学徒、再新培训”的顺序，仍然只读，不增加另一套锁定或提交入口。

收起摘要不再复述两份费用、开关说明和前言，而是直接说明“原学徒增协调、减带教；新培训扩容”。保留原生details/summary，键盘可以连续进入主比较和核对层。没有缩小200%字号。

展开主层同时交代：

- E4支付，各用本角色最后一个介入名额；授权目标失效或已获授权时取消，费用不退。
- 政治、经济、科学、宗教四行配对读取两项**若第31年兑现后的年度来源变化**。科学负项既有负号和强调色，也有“减少”的文字解释，不单靠颜色。
- 原学徒列按当前原点维护折算；新学校列按足额维护1。来源变化不是当地通道净增，也不是第40年预测。
- 承接对象、当前覆盖与若兑现覆盖分别标注，不把同地扩建算成新增地域。
- 主角视角另有“选其一就不能同时签署本轮交班方针”的明确机会成本。林澈视角不重复这条主角限制。

原点“当前 → 若授权兑现”的年度源项、维护系数和完整核对条件留在第二层。它们不与当地通道值混用。旧局明确显示“沿用原授权规则”、原点来源不变；设置亦可核对实际新旧轮值规则身份。整轮交班读层也按真实合同的workload字段区分新旧，取消不重排原点。
