# 跨地取证代价：在花轮数前知道本角色会失去哪条路

## 实玩依据

第23轮已经接住播放转折、十年回顾与来源返回。本轮不重复增加结果面板，而补一个仍影响实际决定的信息缺口：现代规则的三轮调查是“本角色、本窗口、所有地点共用”，原先调查前的新关闭路线提示却只计算本地合同。

只读Chromium实玩从seed0自然新局开始，联合建站、继任招募后到20年：主角在D4读居民证词还余2轮，再读用于另一项本地选择的R0履历后余1轮。原材料只提示轮数变化；到B4才发现此前可达的2轮复核和强化停闸都已无法取证，基本停闸仍可行。30年同一自然路线中，D4一轮本地背景证词也会使B4三轮新校验席不可达，但取证前未提示。

这是角色范围的机会成本，不是全局失败预言。同一次自然实玩后来让主角签共享，林澈以自己的3轮调查筹备B4未来校验，34年完成，40年取得有实际网络支撑的共享结局；第23年原损失仍保留。提示不能写成“所有人都失去这条路线”或“必然坏结局”。

## 规则不变

- 不改调查预算、材料费用、行动成本、概率、名额、到期年份、年度结算、存档版本或结局。
- 不代替锁定/提交检查。取证可达不证明当地能付款、名额空闲、无同格冲突或最终能兑现。
- 不自动调查、切换执行者、改派、覆盖草案、重新锁定或退还调查。
- 不读种子、抽签值、未来结果、未来快照、未读证词正文或草案内部。
- 真实旧版每现场调查流程继续原样；同为现代共享调查规则的旧局可读取此提示，不迁移其历史或世界。

## 只读API

`src/investigation-cross-location.js`导出：

```js
getCrossLocationInvestigation(state, cellId, actorId = 'protagonist')
```

使用现有`getInvestigationPlan`提供的公开行动与材料字段，以同一真实角色枚举当前世界中实际存在且有行动的其他地点。本地损失继续由原计划负责，不重复。

正常返回：

```json
{
  "readOnly": true,
  "actorId": "protagonist",
  "actorName": "主角",
  "budget": 3,
  "origin": {"cellId": "D4", "name": "河港"},
  "otherActors": [{"actorId": "linche", "actorName": "林澈", "budget": 3}],
  "materials": [{
    "id": "resident_testimony",
    "name": "听取岸边居民的证词",
    "cost": 1,
    "portable": false,
    "acquired": false,
    "canInvestigate": true,
    "budgetAfter": 2,
    "blocksAfter": [{
      "cellId": "B4",
      "cellName": "修会藏书院",
      "actionId": "establish_future_check",
      "title": "建立未来校验席",
      "requiredRoundsBefore": 3,
      "requiredRoundsAfter": 3,
      "budgetAfter": 2
    }],
    "enhancementsLostAfter": []
  }]
}
```

`materials`实际包含当前现场全部材料；此例只保留一项以说明结构。

可选强化放入`enhancementsLostAfter`，使用同样的地点、行动与轮数字段，并增加：

```json
{
  "enhancementId": "surveyed_veto",
  "enhancementTitle": "核实撤离路线 · 强化停闸",
  "basicRequiresNoEvidence": true,
  "notice": "基本停闸仍无需取证"
}
```

这个声明只针对真实无需材料的基本停闸，不承诺预算以外的支付或提交条件。

### 不适用与未知分开

非规划阶段、不是0/10/20/30窗口、真实旧版每现场调查规则、当前没有该角色或当前地点没有真实行动，返回`null`。

现代规划的公开资料不完整、8×8地域缺页/重号、公开实体重复身份、当前角色调查库存非法、公共计划无法核对时，返回带以下字段的未知对象，而不是一份空的“没有代价”清单：

```json
{
  "readOnly": true,
  "budget": null,
  "otherActors": [],
  "materials": [],
  "issues": ["当前公开资料不完整，暂不能核对跨地取证代价。"]
}
```

仍保留可确定的角色与起点标识。另一角色的预算单独核对，无法确定时为`null`，不会凭缺页补成3轮。身份/来源合法性由既有行动提供者与保守公开结构检查共同约束；此辅助读取不代替正式存档验证。

## 归因与携带边界

对每份当前能实际支付且尚未取得的材料，分别计算其他地点每条真实合同取证需求：

1. 只报告原来需求不超过本角色现余轮数、这次调查后需求却超过新余额的路线。
2. 已经不可达的路线不再次归因给本次阅读；已取得或预算不足不能调查的材料不构造假想损失。
3. 可携带材料在其他地点抵扣同一材料的实际需求。本地居民证词、维护账簿、继任同意等不能仅因同名ID就在其他地点抵扣。
4. 不改变另一个角色的库存或预算，也不把其有预算写成其必能接替任务。
5. 合同与可选强化分开，损失强化不等于基本停闸被关闭。
6. 已锁复核已拥有必要材料，不会因再花剩余调查而丢失。已锁基本停闸仍保持原草案；即使今后强化机会被花掉，也不把旧草案写成失效。

可携材料的正面目的地仍由现有用途提示说明。本API专门描述本次新增代价，不增设推荐系统或“最佳路线”结论。

## 模型验证

命令：

```sh
node --test tests/investigation-cross-location.test.js
```

实现阶段14/14通过，含：

- 自然0/10/20/30年，共428次真实合法调查，将每个跨地点合同和强化的前后需求与实际`investigate`后的计划逐项对照，核对320个新关闭替代。
- 同名本地材料与可携材料、角色隔离、已不可达、已取得、零/不足预算、已锁草案与明确放弃。
- 新校验、保档升级、失败后续校验与可选强化的真实当期菜单。
- 两个现代旧生产者和原始per-scene生产者在四窗口的完整状态及下一窗口续跑，包含旧档正式恢复；原per-scene返回null。
- 深冻结、无状态别名、种子/抽签/快照/证词正文/草案内部抛错getter、未兑现未来结果不影响当前输出。
- 缺格、重复身份、坏调查库存等返回未知，不提供虚构的“无代价”。

以上是模型专项结果，不冒称全套回归、真人平衡、真机或屏幕阅读器认证。界面、视觉与最终冻结整体验收由本轮独立专项记录补充。
