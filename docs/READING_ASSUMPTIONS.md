# 第十轮：先读合同、核实人物、保留地域清点

以已发布cf36be7a为基线。这一轮改变阅读和来源表达，不改变模拟、存档格式、调查成本、成功概率、随机流程或结局计分，不另加规则版本。

## 免费阅读不等于取得证据

原交接`docs/01_game_design.md`第5节要求三轮有限取证形成选择，并要求选项面板说明确定成本、可能结果、发生时间、条件缺口、失败去向与留下的制度。旧界面把缺证据的整张方案卡禁用，导致玩家先花两轮调查，才能读到失败成本和后备价值。

现在所有当前合法行动都可打开完整合同。缺少的必要材料仍明确列出，锁定按钮不可用；模拟层原有证据校验保持，UI处理器也重新检查当前角色与现场证据。预览不消耗轮次、不读取材料正文、不抽取随机、不改已锁草案或任何世界事实。

`action-preview.js`只读公开行动契约和当前证据。新规则以真实调查记录为准，传入的伪造材料不能解锁；旧规则仍用原现场会话证据，不迁移旧局。返回现场的入口只展开并聚焦对应取证标题，点击“调查”才消耗轮次和读取正文。

示例是第20年裸复核：玩家可先比较55%复核与基础0.30停闸，知道失败不消除危机、费用不退，再决定是否把两轮用于异常曲线或撤离路线。预览不会把两种材料都送给玩家，也不把基础停闸偷偷升级。

## 技术人手不自动成为苏岚的履历

`successor`既用于技术层面的维护安排，也可能来自匿名重建或林澈续约留下带教，因此不能单独证明苏岚担任某个职位。

`story.js`新增只读个人身份核验：规范行动、执行者、日期、证据、兑现与当时真实岗位来源共同成立，才把苏岚称为测站维护者或档案保管员。匿名重建、现存培训点、续约和免费预警不能替她获得这些职位。培训点存在也不证明她已是其中的学徒。

真实强制迁任、尊重或居民协作保留各自来源与责任，不通过后来恢复服务自动原谅或删除历史。旧合同有承诺而岗位来源缺页时，写成来源未知，不把缺页说成当时没有岗位。所有表达保持只读，不改原事件或分数。

## 南岸第23年的清点与今天的服务分开

`local-crisis-record.js`复用已核实的危机历史，再核对原始第23年世界记录与受影响地域。原始条目存放在D4，不代表清点只涉及D4；四地地域档案均可链接该真实世界记录，但不重写其原坐标或来源。

四地世界卡与地域档案，以及有正常入口的现场，提供实际来源入口；南岸新增独立清点页签：有已存非零损失、已存零损失、或明细未知。页签使用账行与形状，不画推断的废墟、伤亡人数或已经修复的建筑。当前教学、互助、维护和停运场景仍依真实机构独立显示。

页签和来源详情直接显示已存数值，0.0001不会被四舍五入成0.00；原历史正文不重写。第23年之前没有已结算标记。真实旧记录只有整体结果时，逐地系数保持未知；不从整体标签、现在的机构、晚期互助或成功结局补算历史。缺少可核实原件时也不补造来源按钮。

三张原创页签为项目原生SVG；它们是档案符号，不是原交接中已有的额外事件。未进行真人平衡、真机或屏幕阅读器认证。
