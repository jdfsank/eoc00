# 第32轮候选2：重读之后，再决定

## 三方面相连的改进

- **玩法问题**：旧“修改安排”调用撤下逻辑，玩家为比较另一个合同，先失去已锁定草稿。现在免费重选保留原安排，明确重新锁定才替换（包括同方案取证后重锁）；真正撤下是独立动作。
- **叙事结构**：新增重选阅读签条，把“已保留的安排”“眼前尚未承诺的备选”“不会返还的调查成本”分开读。原角色、地点及合同名直接来自实际草稿；明确放弃不被写成一份合同。没有编造人物台词或已发生的历史。
- **视觉艺术**：沿用河港档案室的深青/旧纸金色，以双线页沿、暗底原安排签条和宋体小标题形成待复阅文书的层次。不用成功印章，不靠颜色独自表达状态，不增加装饰图片。取消重选是独立可聚焦按钮。

## 阅读边界

原合同的费用、概率、风险、后续责任仍保留在本轮安排；备选合同的完整费用、概率和风险仍在预览与核对页。阅读提示不替代这些字段。实际调查仍按原规则消耗轮次，返回不退款。没有改变 story、simulation、save，未增加世界字段。

签条只在有效的本次重选路线显示，不应被当作持久草稿或历史。该组件自然换行，原生200%字号不缩小，也不靠滚动截断正文。超出一屏时继续滚动阅读，不使用覆盖成本的悬浮栏。
