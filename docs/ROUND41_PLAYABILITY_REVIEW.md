# 第41轮：中断阅读后，回到这份方案

## 从实际阅读断点出发

第30年D4「逐步退出独占控制」预览页刷新后，原「返回现场」回到页首。390px实测合同卡约在视口下方3797px；世界和自动存档并未丢失。这符合原有临时阅读上下文在刷新后失效的设计，不应称为存档故障。

本轮保留这一边界，补上明确的另一条阅读路径：「回到这份方案」。它定位当前仍合法的原合同卡，不声称恢复已经丢失的滚动位置或展开材料。

## 三方面一起改进

- **视觉艺术**：沿用原文书卡，续读落点使用旧纸金焦点线与内侧双线书签。没有新增常驻面板、重复合同摘要或遮挡文字的提示；键盘离开卡片后强调随焦点消失。原场景和人物素材不变。
- **玩法与风险收益**：读完成本、概率和责任后可以继续比较同一方案。刷新或确认页往返不会替换原安排、补证、退款、锁定或推进年份。正常内存来源仍有效时，保留原展开材料与回程逻辑；来源已失效时只定位当前合同。
- **叙事内容与结构**：保留「返回现场」重读完整故事，同时提供「回到这份方案」继续比较。两个动作不再混同，未锁定的阅读也不会被描述为人物已承诺或合同已兑现。原故事正文、合同、历史与结局不变。

## 呈现与边界

原底部比较按钮使用六字标签「回到这份方案」，辅助名称包含当前完整方案名。仅当没有临时来源记录时，在页首原返回控件旁补一枚同名轻量入口。320px原生200%下原标题已经占多行，入口不保证首屏可见；所有合同内容仍完整，长卡需要纵向阅读。

新动作即时核对当前阶段、角色、地点和合法合同。有效来源还须对应同一世界、年份、角色、地域与方案，否则不使用旧来源。没有新增存档字段，不保存DOM索引或像素；旧producer仍通过原存档恢复与当前合法合同读取。角色拒绝不会被旧选择解锁。双击只移动阅读位置，不穿透打开下一阶段。

保留全部旧单测和浏览器脚本。原底部按钮仍保留既有现场导航标识，仅附加明确续读意图；旧「返回现场」的刷新失效断言不改。新专项另外验证显式续读、两种返回边界、真实旧档、原生大字、双击、键盘以及世界与自动存档逐字相同。
