# 第六轮：条件风险、危机来源与地图意向

本轮基线为 `badbe2f7d344fc1e733f64af59f4cca827f6dc38`。这是信息与叙事表达改进，不重新平衡概率、损失、角色能力或旧合同。现有参数仍是可调的原型假设，不是交接资料已规定的数值，也不代表真人试玩结论。

## 第20年：把整轮取舍放在一起

`getCrisisOutlook` 只用于第20年规划窗口。先沿用正式提交核对，必须全部角色锁定或明确放弃、没有同格或资源问题。缺条件时仅说明阻碍，不替玩家补任务。特殊导入若仍有第23年前未兑现的旧合同，暂不推算其未知结果。

- 每项复核保留现有55%、80%或100%的合同概率及兑现年份。旧版确定复核仍按旧合同第21年兑现，不声称它具备新版完整准备。
- 不调用 `randomFor`，不消费或查看掷点，不根据种子猜测将来。双复核列各自概率与“任一成功”分支，不合并成一个未经验证的独立分布概率。
- 只用已锁定证据。调查后未重新锁定的撤离路线，不能把基本停闸0.30静默升级为0.20。多份停闸取较强的一份，不相乘。
- 在独立的只读描述快照上列出已锁定的确定地方合同：河港免费预警/复站、东岸轮值、迁任导致河港服务停止及东岸教学、南岸互助。界面分别标记当前覆盖和合同兑现后的覆盖。
- 先取得既有复核准备，再描述同轮新制度。同轮新办培训不会追溯提升复核成功率。
- 成功复核分支为共同标准失效损失0；全部复核未及时完成或未做复核时，展示最强停闸后备与逐地保护共同决定的损失。完整确定复核不会另画一个伪造的隐藏失败概率。
- 新规则采用现有四地公式，旧规则保留整体互助×0.70、免费预警×0.80，不补造旧档没有的分区明细。

这些是合同成立、按期兑现时的游戏规则条件对照，不是人口、伤亡预测，也不是已发生的历史。投影不推进年份、不支付成本、不创建真实机构和事件。损失参数没有更改。

## 危机记录：发现渠道不是致灾链

第14年共同标准预警与第23年冲击独立于玩家是否建站。旧记录中 `crisis-warning.parentId` 有时指向分站，过去的单链标题会误把“建站→学徒→分站”说成灾难原因，同时遗漏真正及时完成的复核。

`getCrisisHistory` 保留存档的父项与文字原样，仅重新组织阅读：

1. **记录与发现渠道**：只有完整成功来源才能显示建站、培训与分站的资料路径。无建站或来源不足时，展示实际预警并说明未知，不把失败分站补成发现者。
2. **干预与回应**：列出实际签署、兑现或失败的复核、停闸、免费预警与危机前互助，链接至真实行动和结果。尚待兑现不算保护，失败复核不算修正，重复保护不叠加。第30年互助不能追认第23年功劳。
3. **第23年记录**：只读已保存的整体或逐地损失、覆盖；缺失即未知。不从今天的机构重建过去，不把 `averted` 标记换算成缺失的0损失。

来源检查包括执行者、行动年代/地点/ID、事件父项、兑现日期与结果类型。异常来源只保守展示，不扩张旧档拒收范围或更改规则版本。

原生几何筹码以空心方形表示主角、空心圆形表示林澈，只显示当前已锁定草案。短虚线表示意向，不能冒充驻扎或已生效制度。所有合法地域的待兑现事件均显示沙漏，包括B4保档/复核与D5互助，不再使用地点白名单。次生培训事件显示待兑现，不声称角色驻扎。
