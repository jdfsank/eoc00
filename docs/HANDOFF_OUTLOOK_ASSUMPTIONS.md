# 第八轮：整轮交班对照、同伴经历与远港历史

本轮以已发布的4898f629为基线，三项均为展示、叙事与决策信息改进，不新增机制、概率、奖励或存档迁移。没有把当前原型假设改称交接规格，也没有以新预测代替真实结算。

## 玩法：最后一次决策要看整轮合同

自然路线中，同样的“共享纠错权”，另一角色锁定E4培训或D5互助会留下不同的承接能力。原界面仅说明当前缺口，不能看出第31年培训的作用。新`handoff-outlook.js`仅在第30年未提交窗口读取`getWindowReview`已经核验的冻结草案，并列：

- 当前真实人手、授权、异源校验、跨地关系与河港信任。
- 在既有载体继续运行、已锁确定合同按时落实的前提下，第31年的能力变化。
- 第32年后续校验仍需原失败记录和真实测量/教学人手。单列“完成”与“未完成”两种分支；当前无人且没有先行培训时，不添一项虚构校验。
- 实际锁定的方针和每项合同的31/32年时序。培训＋校验用完两个人的名额时，不补发共享/退出决定。互助支持生计，不代替教学、授权或异源纠错。

它不调用逐年推进、兑现或随机函数，不预读种子决定未来，不制造成功事件来欺骗现有来源校验，不展示结局标题。未齐、冲突、缺证据、付不起成本或有未决旧合同，不给完整兑现后预测。撤销与重锁会即时重算，仅基于最终锁定的证据。

## 原规则口径保留

- handoff-v1：承接人手与授权分别核对。新E4培训只提供自己的授权，不替原E4/D5学徒补签；须与不同地域的真实校验连接。共享另需信任。
- 已有tradeoffs但无handoff的旧局：沿用不同地域学校与成功独立载体的计数，仍需至少一处学校；不追补新授权要求。
- 更早的累计旧局：沿用原flags网络次数＋保档＋成功复核，重复培训按原合同累计，不静默改成地域去重。
- 集中协调只是一种方针，不用“保档支点存在”代替完成指令复核，也不把它显示成已经交班。

第40年仍由原模拟规则结算。第23年损失、原复核失败、旧存档合同及已结算历史全部保持。

## 叙事：同行以后仍有自己的选择

林澈40年尾声继续保留第11年入局、岗位交接、第16年缺口和真实补救，再接入她自己的20/30年选择与兑现。复用严格`getDecadeReview`来源核验，只归属规范行动ID对应的执行者；主角同名行动与全局标记不能被写成她的贡献。

成功、失败、取消、明确放弃和缺失记录分别叙述。缺少或矛盾的来源保持未知，不把缺页写成放弃。每个来源按钮指向实际行动、兑现记录或已存危机记录；阅读不改结局评分、世界或历史。

## 视觉：远港是多种制度共存的地方

F6保留既有分站与码头，再表达独立失败底稿、校验工作单和实际完成的对照台。失败记录不会因32年补建而消失；锁定草案仍只是筹码，提交后才有待兑现工作单，成功后才有新桌。分站与校验载体分别停运，收费门槛不被新增校验抹掉。

画面根据F6本地机构、来源事件和实际记录选择，不读全局review来画出不存在的建筑，也不让B4的工作污染F6。所有图形为本项目原创代码绘制SVG/透明PNG，生成脚本与状态测试一起保存。组合变体是视觉状态，不是新增20条剧情。

第32/40年当前没有新的公开AVG现场入口；这些年份的可玩浏览器证据是世界地图，近景选择另由状态单测和原图渲染核对。测试没有冒充真机、真人平衡或屏幕阅读器认证。
