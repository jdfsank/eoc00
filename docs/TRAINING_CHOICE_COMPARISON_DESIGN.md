# 第二十轮：最后一次东岸选择

## 这次修复什么

第30年是最后一次介入。原学徒承接协商与新增培训都可能补上E4的地方承接授权，但一个承认原第7年培训点的职责，一个新增学校和教学产出。不能因为前者即时少花经济与科学，就暗示这些节省还能在下一窗口投资；也不能把同地多一所学校写成多一个自治地域。

本轮增加短的只读比较，并将详细条件留在展开后。它是决策信息改进，不是新的平衡规则，也不声称两方案在现有终局指标上等价。

## 自然路线审计

手动运行：`node scripts/round20-training-choice-balance.mjs`。不新增依赖，不加入浏览器聚合。详细结果写入 `playtest-output/round20-training-choice-balance-results.json`。

固定种子0–19，三种第0年建站、安排或暂缺继任，以及八种第20年安排：复核加免费预警、复核加尊重旧档、复核加迁任、仅复核、仅预警、全放弃、提前培训、停闸加互助。实际调用调查、锁定、提交和年度推进，不更改自然路线状态。

共得到644组两项合同均可选的第30年对照，含52组复核失败。另有14次建站失败，没有原培训链；92个已提前取得学校授权的状态不再提供重复协商。

644组均有以下结果：

- 第40年新培训的E4政治高2.4126–2.4130，经济高0.8348–0.8353，科学高3.9215–3.9218，宗教高1.5432–1.5434。
- 两者结局标题、四地覆盖、已存第23年危机以及人手地域、授权地域、异源校验地域、共享/退出资格相同。
- 两个分支的最终状态均通过引擎验证。

种子0的联合建站→安排继任→B4复核与林澈D4免费预警→共享路线：授权的第40年E4四通道是53.1112 / 47.6689 / 42.8826 / 50.4912；新培训是55.5240 / 48.5038 / 46.8042 / 52.0346，顺序为政治、经济、科学、宗教。新培训科学第33年反超，经济第37年反超。

额外自然灾难、早期夜校与早期培训路线也纳入第30年余额检查。样本最低政治50.6725、经济41.2640、科学39.6093，仍远高于本次两项费用。经济仅2或科学仅1时，授权才有独有的可支付优势；这些特意修改余额的边界被明确标为合成状态，不作为自然平衡证据。政治仅2时，反而只有新培训可支付。原子提交仍由原引擎核对。

真实旧生产者的规划、锁定、提交、结局四阶段均检查恢复和续跑的完整状态相等。这里没有升级旧存档。

这是一组确定性回归样本，不是全部可能路线的穷举，更不是已完成的真人平衡验证。若以现有终局通道和资格衡量，样本中新培训占优；若玩家希望让特定原学徒取得承接权，两项合同留下的责任主体不同。比较不替玩家把后一目标换算成分数，也不标“最优”。

## 数据接口与阅读边界

`getTrainingChoiceComparison(state, cellId, actorId)` 仅在第30年规划阶段、E4、当前可部署角色，且两份真实合同同时存在时返回独立数据；否则返回 `null`。已有合法授权、原培训点失效、来源缺失、旧规则档案、其他年代与地点均不补造选择。

接口列出：

1. 原合同公开费用、本地证词及最低调查轮数。它不查看调查会话，不判断已经取得的材料或剩余轮数；这部分由相邻原行动卡继续负责。
2. 原培训点的固定来源目标，以及新培训新增一处学校、不会替原培训点补签授权的区别。
3. 新增年度来源。授权为零；学校读取引擎统一的 `getInstitutionAnnualSource('school')`，即政治0.1、经济0.25、科学0.65、宗教0.2。年度来源不是未来通道净增。
4. 只假设所选合同兑现且当前其他事实保留时的资格变化。两项都补E4授权，不增加人手地域；缺异源校验、缺跨地关系、尚未承诺或真实拒绝仍分别列出。不读取其他草案、不替另一角色签署方针。
5. 按当前真实覆盖取最大值的条件变化。原培训点维护0.5时，授权仍是0.275，新学校能补到0.55；不能无条件声称两者覆盖相同，也不能相加成0.825。
6. 原目标的兑现核查、费用不退与不改变事项。第23年历史不会被重算，未来第40年仍按实际存续条件核对。

接口不调用年度推进、随机、调查、锁定或提交，不构造虚假草案或模拟存档。历史正文、未读材料、种子、抽样、基线、未来快照、调查会话及当前草案不参与计算。公开事实无法核对时不返回一个看似完整的比较。

唯一引擎改动是新增纯只读导出 `getInstitutionAnnualSource(kind)`，从现有 `sources` 返回独立对象，未知种类返回 `null`。未改现有函数、成本、概率、产出、结算或存档字段。

## 视觉接口

`renderTrainingChoiceComparison(view)` 返回默认收起的原生 `details`。摘要显示两项真实费用及“承接原有职责 / 增加教学产出”的区别，展开才列两份短选项；更长的条件与边界另行展开。没有取证、重锁或支付按钮。

- 根：`[data-training-choice-comparison]`
- 两项：`[data-training-choice="authorize_training"]`、`[data-training-choice="train_network"]`
- 详细条件：`[data-training-choice-detail]`

原合同及行动卡仍是唯一执行入口。比较提供阅读帮助，不复制一套执行流程。

## 验收

`node --test tests/training-choice-comparison.test.js` 覆盖真实第31年兑现oracle、两角色、年度来源、冻结输入、无可写别名、锁定证据不变、私有字段读取负控、贫困边界、真实失败与拒绝、旧档、维护0.1/0.5/1覆盖，以及渲染转义和无变更控件。

全场景手机阅读、放大、结局反馈及浏览器流程由第二十轮整体QA记录；本设计文档不以单元测试代替那些检查。
