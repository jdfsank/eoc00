# 第十六轮：把地方保档接成未来指令校验

本轮沿用已发布 da755ed 的真实内核作为连续性基线。经济5、科学3、三轮取证和第33年核定均为可调的原型假设，不是原交接规格或经过真人验证的平衡结论。

## 实际缺口与收益

B4地方保档已经是交班判断中的异源方法，不能宣传升级才让它首次成为独立来源，也不能把同地两个机构算成两个独立地域。缺口是保档尚未经过实际测量与指令比对，不能单凭保档使集中复核方针具备未来指令校验。本轮给保档路线一项新的付费转换，不提高早年复核成功率，不抵销旧危机。

自然路线：第0年B4保档，第10年自愿招募，第20年B4强化停闸与E4培训。第30年可选择保档升级及集中复核方针。原档继续保留；升级成功才有未来指令校验。退出路线原本就可能具备交班条件，升级不凭机构数量奖励额外自治分数。

## 合同与机会成本

- 新局显式启用 archiveUpgradeRulesVersion: archive-upgrade-v1。第30年B4行动 upgrade_archive_check 支付经济5、科学3，占执行者一个名额。
- 执行者须亲自获得异常记录2轮及B4居民当前证词1轮，耗满本窗口3轮取证。外地证词及另一角色的调查不能替代。
- 第33年原保档必须仍有效运转，同时有真实测站、分站、学徒或教学载体提供测量人手。档案、传讯队、互助仓与另一张校验桌不能充当测量人手。
- 第31年新培训可赶上。但培训加升级占满两个名额，没有第三个名额签署方针。
- 任一来源缺失则取消，成本不退。取消记录区分 archive-unavailable、workforce-unavailable、archive-and-workforce-unavailable。
- 成功创建来源明确的B4比对席，记录实际人手ID；不设 flags.review，不赠授权、信任或方针。新席可正常产出；同地仍只是一地。
- 有有效失败底稿时保留原经济4、科学3、第32年遗留校验；已有完成的指令校验时不再升级。有保档时不提供经济6、科学4、第34年的从零重复建设。关闭的原档不会被升级复活。

保档路线的早期成本与名额仍已支付。相较从零建设，升级少付经济1、科学1且早1年；相较遗留补做，多付经济1、晚1年并额外需要1轮本地取证。三者来源不同，不以失败可补做为由改写当年失败或损失。

## 来源、验证与只读接口

getArchiveUpgradePlan 返回可用性、理由、原档来源、费用和期限。getArchiveUpgradeContracts 返回严格验证过的待核、成功或取消合同，包含 archiveSourceEventId、archiveSourceRecordId、archiveSourceInstitutionId、workforceIds 与 cancellationReason。getArchiveUpgradeSources 默认只返回仍运转的成功新席；requireActive:false 可读后来停运的历史完成事实。

原档必须来自规范的第0或10年B4 preserve_records 行动、已付成本、成功事件、兑现记录与唯一机构。新合同验证第30年执行者、B4、一个名额、个人取证、本地证词、完整成本、规范ID及第33年兑现。新规则或元数据未知、孤立/伪造来源、篡改动作、复制机构、缺版本合同均不得证明完成，导入、提交及年度结算前原子拒绝。未知升级元数据不得放在任意历史或机构上冒充来源。

getHandoffOutlook 将升级列为第33年条件合同，并识别第31年培训。withoutConditionalChecks 保留未完成分支；原B4保档在该分支仍是既有交班方法。新增 commandCheck 布尔能力单独显示未来指令校验：current 只认实际成功复核或有效的已完成后续/新建/升级来源，projected 还可包含当前有人手支持的条件合同，withoutConditionalChecks 保留现有能力。它不改变原人手、地域、授权、信任或方针字段，也不承诺结局标题。投影不抽随机、不提前兑现，也不承诺原档或人手未来永远存续。
