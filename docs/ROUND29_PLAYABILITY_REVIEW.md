# 第29轮：开场的理由，取证的去向

## 基线与实际体验

开工前核对远程 main 为 `9c520548ae85919d18bd7cdd8d5937ae64d59c99`。本地1209个文件与远程树逐项相同，另存源码、测试、浏览器脚本与素材基线。原有完整单测2738项通过；这不代替本轮修改后的最终回归。

这次没有先增加说明面板，而是分别查看真正的开局和“先读合同再取证”的操作。两个体验断点有共同原因：已有信息没有接到玩家正在走的路径上。

- 手机新局首先展示合同数和调查预算，已有的章节说明与信件在移动布局隐藏。主角身份与河港的委托已写入抵达记录，却需要先主动打开档案才读得到。
- 在D4免费阅读“联合管理”，再由合同入口调查必需材料，实际页面停回通用材料区。即使材料已齐，仍只有泛用“回看方案”，玩家需要重新去目录找刚才的合同。记录中的选择并没有丢失，缺的是可信、明确的返回路径。

## 三方面同时改进

### 玩法与风险收益

为从真实合同进入材料的玩家保留临时书签，显示正在为哪份方案取证、尚缺哪些原必需材料，并提供回到同一免费合同核对的操作。它不调查下一份材料、不锁定任务、不支付成本，也不把材料齐备说成整个方案可成功。

调查预算、地方成本、一次性成功概率、条件取消和角色名额仍由原合同与内核判定。没有证据支持本轮调整数值、退款或新增名额，因此不以交互便利冒称完成平衡。选择仍然可以改变，已花调查仍不退还。

书签属于当前打开的取证路径，不借用持久化的旧选择。角色、地点、年份、世界身份与合同均需匹配；刷新、离开路径、新局或导入不能带来一张误指其他世界的书签。兼容旧每现场预算，不能让现代共享预算规则覆盖旧档。

### 视觉艺术

开场使用轻量信笺排版，直接引用已有抵达记录。它在主要现场入口和原角色控件之后、预算说明之前，不增加强制弹窗。标题与正文保留完整，以字体、左侧细线和留白区别于预算、警告与合同。

材料区使用小书签而非一张新的大型说明面板，返回操作和所需材料状态相邻。完整风险、证据原文与既有合同保留，不靠截断或缩小文字来减少页面长度。新增信笺会占用纵向空间；最终视口、200%字号和地图位置以专项实测为准，不承诺所有内容都在首屏。

没有虚构洪水图像、建筑损毁或角色表情来代替来源证据。原有素材不变。

### 叙事内容与结构

开场先补回“为什么来”的已有事实，避免林澈直接谈“你们的报告”时玩家尚不知自己的身份。只在真实第0年规划阶段显示唯一且来源一致的抵达记录，不提前揭示后来的教师人生和现实冲突。

取证的返回提示回答“刚才为何查这份材料”，让行动意图贯穿材料与合同。标题、材料名称和状态来自当前实际合同；“材料已齐”与“已经锁定、已经支付、已经兑现”保持区别。原故事、人物立场和历史正文不重写。

## 验证边界

本轮修改展示与临时导航，不改模拟、存档格式或原历史生产者。功能专项通过真实控件与实际文件导入区分自然操作和兼容样本；单测中的冲突记录只是负控，不能称作自然存档。

最终完整单测、构建、顺序浏览器聚合与数值对照见 [测试记录](TESTING.md) 和本轮冻结验证。视觉与叙事分别见 [排版验证](ROUND29_OPENING_EVIDENCE_VISUALS.md)、[来源阅读边界](ROUND29_OPENING_READING.md)。没有宣称物理真机、屏幕阅读器或真人平衡认证。
