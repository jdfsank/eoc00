# 第二十一轮：给分工留下真实代价

## 叙事选择

第30年的原学徒合同不再只与新学校争夺一张同等的承接资格。新版明确协商轮值职责与承接权：原团队保留基本读尺和预警，把一部分深入带教转为公开议事、轮值安排和生计协调。学校仍是新增教学载体，原点改排不是另一所学校。

原点足额维护的年度来源从政治0.1、经济0.25、科学0.7、宗教0.1，调整为政治0.5、经济0.45、科学0.1、宗教0.1。实际来源继续乘维护系数。政治、经济来源增加与科学来源减少必须一起公开；这不是给权利打分，也不是一份签名创造了额外人手。四通道是不同能力，不能相加为工时预算，系数变化也不是实际课时的精确百分比。

这是新的具体合同，不是对所有授权或自治作普遍判断。D5同源学徒、此前续约章程的授权、既有学校都没有因此更换工作。第23年记录、原培训来源和已存快照不重写。

## 阅读次序

1. 免费现场与合同先说明需要协商的新职责、科学来源降低、维护依赖和第31年核对条件。玩家不用先花调查才知道机会成本。
2. E4证词才给出学徒的具体表达：可以商量分工，但不能把新责任加在原来的全部课时上。读过材料、锁定方案和付款都不是签名。
3. 第30年已提交回访只陈述拟议排班，明确尚未执行。
4. 第31年实际成功后才记录本地承接签名和开始改排。取消时保留筹备成本，不新增授权，也不执行改排。
5. 第40年最后工作卡与人物回忆回收真实选择。当前原点停运时保留历史签署，明确不再提供来源；当前运转未知时不宣称仍在作用。

不从未读证词、随机抽样、调查库存、未来数值或未来结局倒推人物意愿。

## 来源和兼容

规划文本只在 `getTrainingAuthorizationPlan` 给出新版可用 `.workload` 时切换。回访、十年回顾和末页只采用 `getTrainingAuthorizationContracts` 返回的核实合同 `.workload`，不凭全局规则标记或当前数值猜测过去已经改排。

新版合同使用 `trainingWorkloadRulesVersion: training-workload-v1`。旧无标记局继续原来的授权说明和所有叙事分支；没有用新版词句覆盖旧合同。叙事读取不改变状态，成功签署与当前运转分别判断。

涉及页面：

- `story.js`：E4免费现场、证词、选择提问，完整人物尾声通过真实十年回顾取得事实。
- `riverbank-history.js`：提交、兑现、取消、当前停运与未知。
- `decade-review.js`：最后窗口的实际改排和责任。
- `ending-recollection.js`：最后工作卡的教学机会成本与当前维护情况。
- `handoff-outlook.js`：已锁定合同的条件分支；未兑现授权也不会提前执行改排。
