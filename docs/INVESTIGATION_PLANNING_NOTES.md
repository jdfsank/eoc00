# 第十九轮：先看选择，再花调查

## 本轮先解决什么

本轮不再增加合同，而是修复已经存在的决策入口。现代规则中，每名角色每个介入窗口只有三轮调查，跨地域共用，花掉不退。过去现场先出现可付费调查，行动卡和材料门槛在后；完整合同虽可免费阅读，缺材料提示却不能区分“还没查”与“本窗口已经查不齐”。

自然路线确认的例子：

- 联合建站、安排继任后，第20年主角在D4先查异常曲线两轮、旧现实档案一轮，会失去收集当地居民证词和协商免费预警的可能。异常可带去B4复核，但这不代表D4原本的选择仍可达。
- 首轮放弃、第10年自愿招募、第20年基本停闸后，第30年B4可以从零筹备未来校验。它需要异常记录两轮与B4居民证词一轮；先在D4阅读旧档一轮后，剩余两轮不能补齐。旧预览仍只说缺材料，未显示这个区别。
- 第30年E4的原学徒承接协商需要一轮本地证词，新增培训无需取证。异常曲线和旧档并不解锁这两项当地合同，先查完它们会关闭协商路线，却不会关闭新增培训。

原调查区还通用提示“预算用完仍可基本停闸”，但第30年B4并没有该行动。本轮改为按当前当地实际可用合同说明，不借用其他地域或年代的退路。

## 三方面一起改进

**视觉与阅读顺序：** 将当前行动和最低调查门槛放在首次付费取证之前。调查筹、未读材料物件和简短状态用于读出已用、剩余和不可达，不把方案重复堆成另一份长列表。第20年既有三路线比较保留可直接对照的摘要，详细条件和逐地后果由显式展开进入。

**风险与收益：** 在花费发生前，明确材料成本、取得后的余额，以及这一次调查新关闭的本地路线。只是材料条件可达，不代表渠道余额、同格安排、另一名角色或整个提交已经就绪。调查仍由原真实按钮执行，计划和跳转不自动购买材料，不退款，也不替玩家选择最佳路线。

**叙事：** 先提出这个地点、这个年代真正要解决的问题，再说明各份材料服务于什么决定。材料公共标题和用途不泄露未读正文。听取条件不等于已经同意，阅读旧履历不等于可以重新安排一个人的人生；第30年的旧档不能假装仍解锁第20年的个人选择。E4原学徒证词在行动卡、材料入口与合同预览使用同一个准确标题。

## 计算与兼容边界

- 只读计划使用实际可选合同、实际调查库存和现有材料成本。已取得的可携材料按原规则抵扣，本地证词只在原地有效；不同角色不共享已花轮次。
- “这次调查将失去的路线”只包含调查前仍可达、调查后才不可达的路线，不能把本来已关闭的选择算作本次代价。已取得或当前买不起的材料不模拟再次调查。
- 基本停闸与两轮撤离路线强化必须区分。失去强化条件不等于基本停闸行动消失。
- 已锁定任务保留原证据快照。之后查看计划或追加调查，不会暗中增强旧草案；真实重锁与提交仍走原引擎。
- 不改行动成本、概率、年度规则、存档版本或已发生历史。原非共用预算旧档继续原现场预算流程，不套用现代计划计算。
- 不读取随机种子、抽样、未来损失或未读材料正文来建议路线，不复制假草案进入状态，不返回状态对象的可写别名。

## 仍需继续评估的体验

第30年给原学徒授权与新增培训，是“承认既有人员职责”与“增加容量”的不同选择，不能只宣传较低的即时费用。种子0的一条完整自然路线中，两者都得到成功共享、相同E4覆盖与已存危机结果；新增培训在第40年的四通道均更高。末期节省的资源没有下一次介入可供再投资，因此这一取舍仍需自然维护责任与真人体验的后续设计，不能视作已完成平衡验证。本轮保留真实参数，先让两条合同各自做什么、不做什么看得清楚。

现有结局首图也未充分区分授权既有人手与扩建教学容量。后续可优先改进结局首屏和已有角色尾声的阅读顺序，不必再增加一个来源面板；不得凭画面补写人物当前岗位、谅解或新的同意。
