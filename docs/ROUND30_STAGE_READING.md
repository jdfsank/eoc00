# 第30轮：把最后一段历史送到真正的终点

## 体验证据

本轮从真实当前引擎产生的0→30年全放弃路线开始，以实际文件导入，再通过页面的放弃、提交和略过逐条阅读按钮走到第40年，没有注入伪造的世界字段。

修改前，最后一段回放两处称终点为“第40年窗口”，但引擎到达40年进入 `ended`，没有新名额。最后十年回顾仍显示“可用棋子”；明确放弃的责任句说“下一次介入仍需面对留下的问题”；终局档案的P1卡继续说未来取决于“尚未提交的选择”。这些句子各自适用于较早阶段，放到末页却把读者引向一个不存在的后续操作。

## 叙事与风险收益

用公开年份和阶段确定下一终点。第0—29年的回放仍前往下一介入窗口；第30—39年则前往第40年归档。到达第10、20、30年后，回顾的主要去向仍是当年窗口；到达第40年后，主要去向是结局阅读。归档后的角色数量描述为参与者，不再暗示他们有可用名额。

最后一次明确放弃仍保留其选择与代价，只不再许诺下一次介入。责任并没有因为原型结束而消失，未来的生活也没有被否定；本原型只是没有模拟第40年以后的结果。终局P1卡明确这个范围，而不是提供新预测或改写结局。

本轮没有把“归档”改成更好的结局，没有改变成本、概率、调查、角色名额或任何结果。原历史标题“未签署的下一页”和原文仍然保留：它是当时生成的记录，不是当前界面提供下一窗口的承诺。

## 来源与兼容边界

`stage-boundary-context.js` 只读取对象自身的公开 `year` 和 `phase` 数据字段，不读取草案、事件、种子、随机值、历史正文或机构。只有合法的规划年、0—39年回放以及真正的40年结束状态产生文案；非法阶段组合返回空，不从错误时钟推断可用窗口。带访问器或继承的时钟也不求值。

原 `decade-review.js` 与本轮基线逐字节一致，旧保护清单和断言不变。新增 `stage-decade-review.js` 调用原来源核验视图，仅在真正的40年结束状态、原卡包含该角色第30年明确放弃来源且责任句准确匹配时，返回卡片副本替换那句当前说明。尾随的危机事实、其他字段、非终局视图及原始历史全部保留。缺失、重复或类别错误的放弃记录不会被补造成放弃。存档格式、模拟规则和旧世界不做迁移。

## 验证

新增53项单元测试、既有17项十年回顾与38项第23轮回放保护测试，共108项通过，无失败或跳过。覆盖全部40个回放年份、4个合法规划窗口、真实终局和错误阶段负控；隐藏状态访问器会抛错以防止展示层偷读预测信息。当前引擎、培训轮值前的真实旧引擎、准备取舍前的真实旧引擎分别产生0→40全放弃路线，每个阶段和年份调用展示层前后完整世界一致，结束后原历史与完整存档对象一致且各自校验有效。另对每种真实生产者核对早期视图逐字段相同、终局仅该责任字段变化，以及缺失、重复、错误类别的来源负控。原始视图仍保留原句，适配器不修改它。这些旧档不是删除新版标记伪造的样本。

本说明中的浏览器探索确认的是修改前的症状。新增展示模块接入后的实际按钮、跳转、阅读保留、视口及最终全量结果，由本轮功能与视觉测试记录报告；这里不把单测当作整套浏览器验证。现场人物来源点击后缺少返回原现场路径的另一个发现留待后续，不混入本轮。
