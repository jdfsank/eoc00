# 真实岗位招募与人物尾声

本轮基线为f9f2f462。交接设计 §3要求影响有真实载体，§11要求同伴具有意愿与实际离岗代价，§12要求人物与制度共同构成遗产。**以下具体合同是本轮新增实现假设，不是原规格已锁定数值，也不代表真人平衡已经验证。**

## 没有岗位，不制造离岗损失

旧版无建站或只在B4保档的路线仍能购买两种D4招募合同：经济1的暂缺继任与经济5、科学2、额外取证的安排继任。当地没有可交接机构，后一项的价差没有对应岗位收益，前一项却宣称会减产停运。

新局使用独立`recruitmentRulesVersion: recruitment-v1`，不改变已有`aftermath-v1`旧局：

- D4没有活跃且维护大于0的测站/小型档案岗位时，只提供“招募林澈 · 自愿同行”。经济成本1，仍占第10年唯一行动；第11年完成入局，第20年起可部署。B4独立档案不算河港岗位。
- 不增设惩罚，不赠机构、苏岚继任同意、地方信任、授权或教学网络。测站建设、保档与夜校仍是放弃本次招募才能选择的机会成本。
- 成功测站和失败后的小型档案仍是真实岗位，保留原两种继任选择、成本、产出减半及第16年停运等后果。
- 已停运或维护为0的载体不被当作仍需离开的现职。历史原址继续保留，不补写现有产出被减半。

第10年里程碑、现场对白、岗位调查、方案预览、兑现记录和第20年拒绝理由一起遵循该事实。对真实旧局的虚构空岗描述，不篡改历史条目；新的只读尾声会把合同里的承诺与实际岗位分开说明。

## 岗位合同可追溯

提交时把真实`departureRoleIds`同时记录到行动来源和待兑现事件。新合同要求事件ID、行动ID、执行者、地点、日期、两处快照一致；签署和兑现时必须与实际岗位集合一致。兑现后需要对应的结果记录，不能只改事件与行动来源制造一段已完成历史。

直接锁定、伪造草稿、空来源、协调清空岗位快照、把失效载体塞入快照、未知招募动作及缺规则版本的新动作都会在写入前拒绝。后来真实停运不会倒过来使原岗位快照失效，不能用第40年的状态改写第10年的事实。

## 第40年收束人物，不重算结局

`characterEpilogue`是只读叙事，不给`getEnding`加分、不改变已存终局记录，也不在较早年份预写尾声。它核对成功事件、带正确年代/执行者/地点的行动来源、对应兑现记录；旗标或一段孤立文字不能证明个人决定。

- 林澈：区分未入局、无岗同行、安排真实继任、留下真实缺口。实际第16年停运与后来第21年补救同时保留。
- 测站免费预警修复不等于从未停运。失败档案停运后另建传讯队，也不冒称旧档案站已经复工。
- 接班有人不等于维护资金到位。第16年收费分化在人物尾声中仍有位置。
- 苏岚：尊重当前选择、强制迁任、参与免费预警、只有接班承诺、没有明确去向记录分别叙述。不把后来繁荣或修改的信任旗标写成她曾同意。
- 每段可跳转到真实来源。缺失日期、来源断链、年代/地点错配时不确认那项个人事实，不用今天的结果补写缺失历史。

没有新增人物寿命、婚姻、退出队伍、好感或善恶资源。人物尾声不能弥补尚未写作的完整人生。

## 地图分别表达缺人和失修

本轮不更换全部建筑纹理。地图的空班标记只由`staffingGap`驱动，屋顶修补与失修色只由`maintenanceGap`驱动；两种原因并存时同时显示，停运封板优先。恢复后重绘清除旧提示。提供非颜色文字和单色截图验证，避免维护满额但缺人时仍被画成坏屋顶。

## 真旧档与风险收益证据

实际f9f2f462内核冻结于`tests/fixtures/pre-recruitment-simulation.js`（原blob `75428c09ae5ef77cb2b03c2b354cb5623c533fee`），仅调整JSON路径。6条真实旧路线×规划、锁定、提交、兑现、结束5阶段，共30组完整状态与结局逐年续跑不变；更早版本夹具继续保留。

新无岗自愿招募与真实旧低成本路线在相同后续安排下，逐年棋盘、快照、制度、危机及结局机制结果相同。修正的是虚构损失与无收益价差，不靠额外危机或补偿分数改写平衡。长期人力供需和招募成本仍需真人试玩。
