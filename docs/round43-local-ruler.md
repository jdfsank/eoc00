# 第43轮：看见投入所占的当地余量

## 三方面评估与改进

第42轮账页已让玩家知道成本来自哪里，但多通道成本仍要逐个心算，容易把支付后余量和未来收益混在一起。本轮沿用旧纸账册与原数字，在每条通道下增加固定0–100的细刻尺：斜线标出本项占用的现有通道，实色标出单项余量。空白部分不是缺口；真实不足仍由原数字明确说明。图例标明满格100，不把刻尺画成成功概率。

- **视觉艺术：** 低对比暗底、细边框与斜线保留账册风格；不用红绿作为唯一含义。图例色块与“斜线/实色”文字绑定，原生200%下不再孤立换行。小屏保持原字号与正常纵向阅读，没有压缩全文进一屏。
- **玩法风险收益：** 刻尺只画现有通道；不足、归零与极小差额依然以未经舍入判断的原文本为准。读数不扣款、不合并其他草稿、不替玩家判断整轮可承担性。固定100刻度方便在多条通道间比较，而不是每行自动填满造成误判。
- **叙事内容与结构：** 新增“账页记录投入，收益仍须等待合同兑现”，把承担、提交与后续兑现的时间关系接起来。原成本、时点、收益、风险四项原文与先后顺序不改，也没有新增人物同意或改写历史。

模拟、费用、概率、存档格式与旧生产器均未改动。

## 测试边界

最终专项先独立通过106项，然后追加到原74套浏览器链末尾。冻结最终输入后，一次完整75套浏览器聚合实际执行27368项，全通过；3001/3001单测、生产构建、888条件矩阵均通过。644自然训练取舍对和10角色机会成本对审计完成，仍保留balanced:false，不声称全局平衡。624个运行输入在运行与独立审计后均保持一致，50套内嵌hash由独立算法复算吻合；25套旧测试无内嵌hash的限制保持不变。详见[机器验收](round43-verification.json)及[原始日志与全部75份报告](round43-evidence/raw-validation.tar.gz)。所有旧脚本保持原字节，不降低超时或断言。新增单测覆盖四个自然路线快照的公共合同，以及独立合成的归零、短缺、微量和不合法输入；合成值没有注入真实浏览器世界。浏览器刻尺专项实际覆盖可承担的双通道合同，不能据此声称所有不足状态都经过视觉实玩。

最初一次专项因clientWidth整数舍入与实际CSS小数宽度不一致而失败；改为用边界框减去边框取得实际内容宽度，保留原精度阈值后重跑。独立复核还发现200%下图例色块分离，已修复并重新截图。没有跳过失败检查。

远程CI与本地结果分别记录；主分支不随候选更新。旧CI运行42547059740仍为失败，返回的步骤与日志缺失，原因未知。本轮不修改工作流、权限或支付设置来绕过CI。
