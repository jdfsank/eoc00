# 第十五轮 · 迁任目的地的回应与原址来源

## 叙事缺口与改进

种子12正常路线的第0、10年放弃、第20年主角在河港 D4 执行迁任，第21年会在东岸 E4 生成一所学校。此前第30年东岸只有通用课堂叙述；未招募林澈的路线也没有同行者的分歧段，因此这里读不到这一决定的个人代价。地域档案按原始 `cellId` 过滤时，还会遗漏学校真正的河港来源。

本轮只加目的地短回应和只读来源接口，不新增人物岗位、对话选择或制度效果。回应分别说明这所学校的现状、与东岸其他教学载体的区别，以及原迁任记录实际保留的苏岚反对证词。当前机构仍运转，不证明她今天继续任课、自愿留守、同意调令或原谅执行者。停运也不删除那次决定与反对。

## 纯函数接口

`getRelocationDestination(state, cellId = 'E4')` 位于 `src/relocation-history.js`。

- 非 E4、没有兑现/学校来源、只有草案或尚未兑现时返回 `null`。
- `status: 'recorded'` 表示行动、事件、兑现和唯一目的地学校的来源一致；`activity` 单独取 `active`、`stopped` 或 `unknown`，不把当前状态当成过去来源的替代品。
- `status: 'unknown'` 表示存在迁任兑现/载体线索，但来源缺失、冲突或歧义。此时不提供学校身份或来源链接。
- `title`、`summary`、`paragraphs` 是可展示短文；`schoolId` 只标识这一次已核实的学校。
- `sources` 为已核实的原条目引用：`{ recordId, cellId: 'D4', year: 21, label, summary }`。只包含原迁任兑现的 ID，不新建 E4 事件，也不复制、挪动或重写历史。UI 可从 E4 引用它，打开后仍读真实 D4 原条目及因果链。

来源检查复用既有行动→事件→兑现校验，并检查学校的精确 ID、地理位置、年份、类型、源行动、源事件，以及跨 `history`、`events`、`institutions` 的 ID 唯一性。显式错误的现实或执行者字段不通过。相同行动产生多个学校或异地重复载体时也不提供来源链接。执行者从原行动 ID 读取，不把当前查看角色或后来同行关系当成执行者。

既有 `getRelocationHistory` 的原文旁注与语义不变。它对河港早期停运目标的未知，不等于迁任目的地本身未知，所以新接口独立核对学校来源。匿名夜校和轮值学校、学校名称、强迁或信任旗标不能替代迁任来源。原文缺反对证词时明确保留缺页，不从旗标补写她的态度。

## 当前状态与共存

确认运行需要布尔 `active` 和有限、范围合法的维护值；明确停运或零维护不写成继续授课。字段缺失/非法时显示当前情况未知，也不让东岸通用开场把未知写成已停课。其他学校/培训点有独立现状，不被同一条迁任来源吞并；只把它们称为其他教学载体，不从匿名集体中指认个人。

现有学校的课堂开场、当地承接与异源校验的区别、第23年危机记忆，以及有真实同行来源的林澈分歧仍保留。没有同行者时也能读到迁任的目的地回应。

## 验证范围

新单测 `tests/relocation-destination.test.js` 使用当前引擎与9份真实旧生产引擎生成历史，不更换规则标记伪装旧档。覆盖自然放弃路线、草案/提交/第21年兑现、匿名夜校和轮值对照、既有学校和培训共存、同行/未同行、真正旧版林澈执行、停运/零维护/状态缺页、原始 D4 归属、缺源/重复/跨表冲突/错误现实、原文证词缺页，以及到第40年的继续模拟和结局不变。

接口与场景均只读，不接触随机数或证据/草案，不修改模拟、费用、危机、结局和存档规则。畸形来源的变体测试是保守展示边界，不声称这些状态都能通过正常导入。浏览器中的来源导航、窄屏与键盘验证由整合测试另行记录。
