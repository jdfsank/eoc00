# 第34轮 · 候选4：让代价与责任也能直接读到

## 从实际体验出发

候选3把原案与备选放在同一账页，却仍是一段很长的连续阅读。独立使用真实控件走完0—40年后，另以商会原案与官署备选复核：320px原生200%下账页高7372px，风险在标题下3609px，责任在4474px处；页内唯一控件是折叠标题。键盘从该标题按Tab会越过整个账页，到后面另一份合同的年度来源说明。完整原文虽然存在，找到其中的代价仍需要大量滚动。

本轮仅改这一处阅读结构，不再给安排页叠加摘要。安排页已有成本与风险跳转；新的目录补在原来没有目录的对照账页。

## 三方面改进

- 视觉：沿用青绿、旧纸金与文书双线，以五个页签构成账页目录，标准字号保留编号，200%隐藏装饰编号并排为两列。成本、时间、收益、风险、责任获得相同层级；不是分数排名。实线原案和虚线备选仍保留文字标识。原生200%不缩字、不截断、不固定遮住内容。
- 玩法：读者可直接比较真实风险或责任，逐项读完返回目录，也可从账页底部收起并回到原折叠标题。目录只定位文字，不调查、不收费、不锁定、不刷新原证据，也不替玩家选最优。
- 叙事：把承诺的代价与责任提升到和收益同样可达的位置，保留条件语气和原合同全文。五组文字没有换写，原案与备选仍是替代关系；没有新增人物台词、补造过去、提前揭示随机结果或把预期写成已发生事实。

## 输入与边界

跳转只在当前已展开的对照账页内寻找固定标题，焦点与阅读位置一起移动。不会改变URL片段或增添浏览器历史，也不新建存档字段。返回目录仍保留账页展开；底部收起返回同一个原生summary，重新展开文字不变。键盘按Enter可以激活链接；重复指针输入沿用既有保护，防止页面滚动后第二击落到其他操作上。

原案仍用锁定时证据，备选仍读取当前已取得材料。基本停闸0.30与补证后的备选0.20不得静默合并；明确放弃不伪造合同，跨地点成本不相减成全图余额。

## 验证记录

开发专项首次在底部收起后发现：标题已有焦点且可见，但鼠标触发时没有焦点环。已为该返回目标提供明确焦点环，保留原失败截图和报告；不是降低断言。旧候选3专项157项在初版已通过，最终仍须随全量回归重新执行。

最终结果以本轮冻结验证和TESTING中的实际结果为准。长账页完整文字仍然很长，目录改善到达路径，不声称缩短了所有阅读量，也不声称真人、真机或屏幕阅读器认证。

视觉复核中，初版200%单列目录将第五项责任推到下一屏。主动中断当时尚未完成的单测和浏览器聚合，保留中断日志，改成两列后重新冻结并从第一套重跑。完整合同与32px根字号不变。不能把早期部分通过拼接成最终通过。

## 独立最终QA

最终冻结后执行：导航823项、当前/旧档兼容222项、连续Tab/Shift+Tab/Enter163项，共1208项全部通过。42张原始PNG与54组重复输入序列独立核验；原案0.30与补证备选0.20、跨地点、明确放弃、真实旧producer、设置/刷新/离开与完整世界/自动存档均验证。不同脚本原始源码hash算法分别重算并匹配，未把不同hash当成源码不同。

首次触屏检查误把仍从detail2/3开始的连击叫作新一组手势，失败记录保留。最终在两组独立双tap之间等待700ms并断言首击detail1，同组第二击仍立即触发；这限定了实测范围，不声称所有连续快速点击模式都通过。
