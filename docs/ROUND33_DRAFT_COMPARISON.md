# 第33轮 · 候选3：把两份安排放在同一页读

## 一个真实的决策缺口

候选2让免费重选不再丢失原草稿，但原安排签条只有标题。玩家比较商会与官署时，必须记住另一页的经济3、85%、第2年，才能与政治3和经济4、80%、第3年比较。提高成功率或减价不能解决这份阅读负担。

本轮在有真实重选上下文的预览和确认页增加「对照原安排与备选 · 免费」。它是默认关闭的原生details，不增加第二个锁定入口。展开后按当地成本与名额、时间与判定、目标、风险、责任五项逐对阅读，完整候选合同仍在原位置保留。

## 视觉与内容结构

比较账页沿用深青与旧纸金色、双线页沿、衬线小标题。原安排使用实线，备选使用虚线，同时明确标注「保留原安排 / 若改为此方案」；颜色不独立承担意义。宽屏两列，窄屏每项内上下相邻，不把全部原案列完才去看备选。

原生200%文字保持32px根字号，不截断、不压小。账页默认折叠，避免原安排签条之后再强制增加长篇阅读。展开内容可以超过一屏，元素长截图不代表首屏全部可见。

责任文案来自已有真实合同与对应责任说明。新导语只组织阅读，不增加人物台词、过去事件或未来保证。两份安排是替代关系，不是叠加收费；跨地点成本不能当成同一个钱袋相减。

## 只读数据边界

`getDraftChoiceComparison`先核对真实本轮草稿身份。原案以 `draft.evidence` 读取当前有效合同，备选走当前公开预览；所有输出深拷贝。没有调查、模拟分支、随机读取、付款、锁定、退款或新存档字段。

原B4基本停闸0.30在后来取得撤离材料后仍然是0.30，眼前备选为0.20。比较明确提示新旧材料不同，只有明确重新锁定才纳入新材料。已明确放弃显示无合同，不伪造一份零风险方案。旧每现场材料继续由旧会话传入，原合同仍用自己的快照。

费用、概率、发生时间与合同目标/风险沿用完整预览的格式函数。建站旧规则仅复用已有兼容显示，不把建站说明器用作通用冻结合同读源。全轮余额与冲突仍由原提交核对处理，材料足够不等于整轮可提交。

## 验证与限制

新增模型/view单测14项。正式浏览器入口 `scripts/round33-draft-comparison-test.mjs` 从真实控件创建商会草稿，再比较官署，逐字比对候选四项与原完整合同，验证开闭、确认、取消和完整世界/自动存档一致；覆盖320/390/430/1280标准文字以及320/390原生200%。

独立QA另测原冻结证据、跨地点、明确放弃、旧producer文件导入、重复操作和退出失效。基线脚本、既有单测、模拟、存档、原故事、所有原素材不改。完整结果以 `round33-verification.json` 和 `TESTING.md` 为准。

开发专项两次失败属于新脚本假设：程序聚焦之前尚未进入键盘模式，以及再次载入错误期待世界页而不是已保存的安排页。分别改为真实键盘输入和稳定的设置入口，保留失败证据后重跑；没有放宽原断言、截图时间预算或修改生产以迎合测试。没有真人平衡、物理手机或屏幕阅读器认证。
