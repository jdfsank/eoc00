# 调查前条件比较：公开规划与只读边界

第17轮实现 `getInvestigationComparison(state, cellId, actorId='protagonist')`。它是第20年 B4/F6 的免费条件说明，不是新草案、调查记录、保证成功的试算或整个游戏的最优解。展示名称为“调查前条件比较 · 只读假设”。

## 适用范围与旧档

同时要求 `planningRulesVersion='tradeoffs-v1'`、`crisisRulesVersion='coverage-v1'`、第20年且处于 planning。原整体危机规则或原场景调查规则的旧档不显示此比较，也不迁移规则。已启用上述两项规则但早于 aftermath 的档案可显示，其现有身份、人手与互助规则仍原样使用；测试以真实结算证明一致。第0/10/30年、回放、其他坐标均返回 null。

## 三种公开合同与预算

- 交叉复核：仍缺异常水位记录时再花2轮；已有可携带记录则不重复付款。经济4、科学3，第22年到期。当前真实准备决定55%、80%或100%。成功纠正四地共同指令，失败保留当轮其他实际安排提供的保护。
- 强化停闸：仍缺撤离路线时再花2轮；政治4，第21年到期，确定基数0.20。
- 基本停闸：不追加调查；政治4，第21年到期，确定基数0.30。
- 调查已花不退。所需追加调查超过当前余额时标为不可达，不给整轮数值。如果当前角色已取得路线，重新锁定会自动包含该材料，因此基本停闸行标为不可用；先前已经锁定的基本停闸并不会因此被改写。要纳入新材料仍须重新锁定。

复核与强化停闸竞争同一角色3轮预算。材料正文仍须真实调查后才读；比较只返回公开材料名称、调查是否取得及费用。比较不会替其他角色安排放弃，也不会把当前角色的旧草案与假设方案重复计算。

## 共享规则与状态边界

实际 `getWindowReview` 和比较共享公开规划检查：当前窗口、实际角色安排、同格冲突及逐地通道成本。实际已锁事实统一由 `getLockedPlanningFacts` 读取，仍逐项核实锁定快照中的材料确有调查记录以及必要证据是否齐全。该读取器没有跳过证据的参数。

假设行只构造公开合同描述，不构造 locked/passed 草案，不调用 investigate、lockTask、passTask、commitWindow、advanceYear、randomFor 或 getWindowReview，不克隆整局后篡改证据。真实提交仍运行完整 validateState，保留全部存档、来源及取证约束。

比较的公开检查不访问种子、随机数、未来结果或未读正文。只核对所需公开结构：唯一身份、当前演员和草案、调查预算及材料、地方能力和制度维护。私有或无关字段不枚举，不把整个 flags/institutions 交给 structuredClone。缺失、重复、非法或无法核对的公开资料保留未知；不以简化模型生成数值。

## 条件后果的数学

实际锁定对照与假设比较使用同一 `projectCrisisContracts`；逐地损失与真实第23年结算共享 `getCrisisLosses`。每格先按现行四位精度舍入，再求四地平均并舍入，不能先平均覆盖再套系数。

确定地方合同只在独立公开投影中考虑：居民传讯、恢复测站、轮值培训、南岸互助及迁任。保留其他角色实际锁定地点、材料快照、成本、到期及概率。未安排、同格冲突、余额不足、行动不可用、取证失效或第23年之前尚未兑现的既有合同，都不产生整轮后果。陌生待兑现合同不视为已经发生的保护。

同轮培训可改善其所在格的兑现后覆盖，但不追溯提高此前复核准备。双复核分别列出概率，不假定独立而合并概率；任一成功即可纠正指令。双停闸采用较强一份，不相乘。若现有或任一复核保证成功，`fallback.possible=false`，界面隐藏不可能的失败后果。

损失系数是原型规则，不是人口、伤亡、现实概率或整体胜负预测。费用、角色机会、长期能力及叙事承诺仍不同。没有调整平衡数值。

## 验证

`tests/investigation-comparison.test.js` 覆盖：

- 种子1保档→自愿同行、种子12首轮放弃→自愿同行、联合建站→安排继任的公开比较。林澈D4居民传讯保留；80%/55%路径失败平均0.9431、强化0.1886、基本0.2830；100%路径不显示失败，强化0.1239、基本0.1859。
- 16个固定种子、两类准备、两处地点、三种假设分别走合法调查→锁定→实际第23年结算，共192条实际分支对照。
- 深冻结输入、seed/随机roll/隐藏正文/无关私有字段抛错 getter、返回对象递归无别名，以及原存档、草案、预算逐字不变。
- 缺失/冲突/不可用/不够付款/未兑现合同/畸形预算与身份、证据不可伪造、已有调查不退款、携带材料、后调查不改旧锁、双复核不合并、双停闸不叠加、同轮培训不提高复核概率。

原 crisis-outlook、window-review、tradeoffs 回归仍须通过；独立审计、界面及浏览器覆盖由第17轮配套测试提供。
