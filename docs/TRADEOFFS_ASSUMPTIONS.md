# 准备、风险与取证取舍 · 本轮新增假设

本轮对照交接包 `docs/01_game_design.md` §2、5、6、11、12 与 `05_data_contract.md` §4、9。原规格要求证据改变方案、维护者与独立来源有实际作用、危机至少存在一种可达的缓解办法、规则语义版本化。**下列准备组合、55%/80%概率、调查权重及跨地点预算均是本轮设计提案，不是原规格锁定数值，也未经过真人平衡验证。**

## 问题与保留的价值

上一轮复核不检查来源和人手，一份异常曲线就确定消除四地危机；同样消耗一个行动的停闸只有剩余减伤。无建站、无早期准备、低成本招募能稳定取得额外行动，并以零危机和共享结局结束。另一方面，无建站但认真保存档案、培养地方人的路线本来就应当有效，不能以强迫建站或凭空增加岗位损失来修复。

本轮没有提高所有通道价格。通道成本仍表达当地的短期组织负担，不被改造成稀缺货币。取舍来自提前做什么、调查哪份材料、是否保留另一个人的危机后备行动。

## 复核准备与时间合同

新局存入 `planningRulesVersion: tradeoffs-v1`，与 `crisisRulesVersion: coverage-v1` 分开。

- 异源档案：运转中的保档机构，或可追溯到成功联合建站且保存独立旧记录的机构。
- 测量/教学人手：运转且维护大于0的测站、分站、培训点或学校。小档案站与临时复核记录不能自行充当这项人手。
- 两项齐备：完整复核，确定在第22年完成。
- 仅一项：紧急复核，80%在第22年完成。
- 两项皆缺：紧急复核，55%在第22年完成。
- 成功截断此次四地共同标准失效，不表示洪水没有上涨或所有家庭已有预警。失败不退费用，保留整理记录的机构，但不设置已完成复核，不把未确认记录算作自治能力。
- 准备、证据、概率和到期时间在统一提交时写进事件合同。另一角色同窗口新办学校不会事后把已承诺的55%变成80%；重读、刷新与播放速度不重掷。

**保留确定有效的无建站路线：** 第0年B4保档 → 第10年E4夜校 → 第20年完整复核。它的代价是没有同时招募第二名介入员，也没有自动获得河港预警覆盖或苏岚的合作。它可以支持有准备的退出方案，不能把零共同失效当作所有目标都已经完成。

## 停闸不是失败选项

基本停闸仍无证据前置，确定把四地损失基数降为0.30。花2轮核实撤离路线后，基数为0.20。其后仍按各地覆盖、来源保护和互助计算。

复核与停闸可以由不同角色在不同地点安排。紧急复核失败时，停闸仍提供确定保护；充分准备的确定复核与停闸则有本次危机保护重叠。窗口核对会分别说明。双份停闸只采用较强的已兑现方案，不相乘；双地紧急复核分别判定，成功保护只生效一次，机构产出仍各自保留。

## 有限调查，但保留救济

- 每角色每窗口共用3轮，记录在世界存档的 `investigations`，不再只保存在可丢弃的UI会话里。
- 异常曲线与撤离路线各需2轮，其余材料需1轮。两种危机调查不能由同一角色在一个窗口全部完成。
- 异源洪水记录、异常曲线、撤离路线和R0旧档可随调查者跨地点使用。重复阅读不收费；居民证词仍注明原地点，不拿另一地居民的合作代替当地同意。
- 调查前显示成本，返回、换地点、读档、删除UI都不能补充轮次。不同角色有自己的3轮。
- 没有轮次或选择了别的证据时，基本停闸和无证据方案仍可用，不制造危机必败死局。
- 锁定与提交核对权威调查记录，不信任外部传入的证据数组；伪造草稿、未知规则版本或超预算存档会被拒绝。

## 结局能力不按重复按钮计数（0bcabc5规则记录）

本节保留0bcabc5发布时的结局判据，适用于未带`handoffRulesVersion`的已有存档。当前新局已按[交班能力说明](HANDOFF_ASSUMPTIONS.md)分开判断培训人手、独立校验和地方授权，不再用`school`标签排除既有学徒。本文其余调查、危机概率和损失规则不变。


新局按不同地域现存的学校与成功工作的异源校验载体计算自治支点。同一E4再培训会增加产出，但不增加第二个地域；B4保档后再复核也只算一个支点。共享与退出还需要至少一处真实教学维护网络，共享另需地方信任。失败的临时复核不能冒充已具备的纠错能力。原建站培训链可以提供复核人手，但不自动算作独立自治来源；学校（包括迁任学校）代表承接人手，并不天然拥有异源方法，需要另一地区的真实校验支点配合。

这仍是粗粒度原型，未模拟所有人力分工或证明相隔两地就必然具有完全独立的知识来源。下一轮可检验网络的实际维护职责，而不是只扩大数量。

## 兼容与证据

没有 `planningRulesVersion` 的旧局继续原有场景调查、确定复核、到期时间及结局计分。导入不会升级旧规则、取消已锁定草稿或改写已结算危机。回归使用从实际提交 `0a64767` 冻结的旧内核，在规划、已锁定、已提交、已结算四个阶段生成存档，再用当前内核继续，对比危机与64格状态。

固定种子0–99的四条对照路线都在第20年同时安排河港传讯、第30年共享＋培训：

| 第20年保护路线 | 零损失局数/100 | 平均损失系数 | 最坏损失系数 |
|---|---:|---:|---:|
| 无准备紧急复核 | 54 | 0.4338 | 0.9431 |
| 早期保档后紧急复核 | 71 | 0.2735 | 0.9431 |
| 基本停闸 | 0 | 0.2830 | 0.2830 |
| 调查路线后的停闸 | 0 | 0.1886 | 0.1886 |

这些是固定种子样本，不是概率估计证明或“已经平衡”的认证。理论上80%复核的期望风险与20%停闸接近，但尾部损失不同，且保档带来后续自治能力。样本中的无准备复核46局未形成共享所需能力，保档路线即使紧急复核失败仍保有真实档案与学校支点。历史损失不会被成功的终局方针抹去。

核对页展示草案实际锁定的结果。锁定基本停闸后新调查的路线不会静默改变草案：提示仍是0.30，需修改并重新锁定才采用0.20，已调查材料不重复收费。
