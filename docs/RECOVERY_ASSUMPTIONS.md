# 第七轮：迟到的校验、十年回顾与南岸互助

基线是 `76dfe4d2816bdec1912814133dda8372b9fb52be`。下面是本轮可调设计假设，不把新玩法与数值冒充交接包的原始规定。

## 玩法：失败之后仍能做工作，但不能重写过去

第20年紧急复核失败留下真实记录，过去只有“继续整理”的文字，却没有最后十年的可执行任务。本轮新局增加 `recovery-v1`，在第30年给B4或F6仍运转的真实失败记录提供 `complete_review`：

- 支付当地经济4、科学3，重新调查异常曲线需2轮，并占执行者当窗的一个名额。
- 第32年核对原失败记录是否仍可用，以及是否存在真实运转的测量或教学人手。传讯队、档案本身和另一份校验记录不能冒充测量人手。
- 当前没有人手，也可以让另一角色第30年安排培训，第31年实际到位后支援第32年校验。两个名额因此都被占用，不能同时再签交班方针。
- 原记录停运或届时无人支持，合同取消，费用不退。预览、锁定、整轮核对与提交历史都明确这项条件，不写成无条件必成。
- 条件成立时创建一个新的、面向未来的校验载体；原失败事件和原载体保留。不会把 `flags.review` 改成曾及时成功，不重算第23年损失、覆盖、棋盘快照或危机来源。
- 新载体可作为未来交班的异源校验来源，但不附赠培训、地方授权、信任或政策。仍需不同地域的已授权人手。已有合适人手的路线可以由另一角色签署方针；从零补培训的路线可能只能留下能力，来不及完成本阶段的交班。
- 若明确选择集中协调，后续校验的存在也可以反映在未来协调能力中，文字同时保留它没有赶上第23年。没有新增或假称模拟了下一次洪水。

这一选择不是按失败补分，也不是不建站路线的额外惩罚。它把后续工作变成真实成本与机会取舍，保留灾难、早期失败和未签方针的结局。晚期数值仍需真人试玩。

## 来源、边界与旧档

失败来源须有一致的第20年行动、原合同版本对应的第21/22年失败、结果记录和规范机构ID。新合同冻结原事件及机构ID，成功记录实际参与的人手ID。人手核对真实来源类型和培训/分站父链；搬用传讯队、克隆机构、改地点、改年代、清空证据或更换行动ID不能伪造后续校验。

判断在写入前进行。缺人或原机构停运是正常取消分支，不靠破坏存档或先扣费再报结构错误表现。成功后原人手停运不抹掉历史完成记录，但最终交班只计算当时仍运转的授权人手和校验载体。

没有 `recoveryRulesVersion` 的旧局保留原行动集合、旧合同和旧结局计分，不自动补发第30年任务。真实76dfe4d原内核冻结于 `tests/fixtures/pre-recovery-simulation.js`，原blob为 `8b6870eeed3e738b1730e3bb827596e3ac6aa883`，只调整JSON导入路径。36组真实旧局在不同阶段导入后逐年完整状态与结局一致。设置显示本局采用的新旧合同模式。

## 叙事结构：上一窗口的选择不能消失

`getDecadeReview` 是纯只读摘要。第10、20、30年以及40年回顾，按上一窗口当时可用的角色，展示“选择 → 真正兑现/失败/取消/待兑现 → 仍需承担的责任”。明确放弃也有自己的记录和来源；缺页不能被补写成放弃。

- 来源按钮指向实际历史条目，原始逐年记录仍可展开。
- 第0年建站的学徒传播不偷算成第10年招募的功劳。
- 旧无岗招募不把历史文案中的虚构空岗改述成事实。
- 后来的互助与校验不能抹去已记录的第23年损失。
- 不新增人物人生、好感数值或结局奖励；回顾与导航不修改世界。

## 视觉：同一片南岸，两套不同的服务

南岸D5的新原创场景与地图道具同时表达低矮高脚物资棚和无顶读尺围座。互助、教学各自判断存在与运行：一项停运只封闭该项，另一项继续运转；两项停运都保留原址。重新开互助仓，不凭空重启旧课堂。

共六个状态变体，包含互助单独存在与教学/互助共存的各自开闭。草案或待兑现不提前画成机构；重复互助只显示实际服务状态，不画成多层洪水保护。图注在这些新图下方排版，避免普通320px字号遮住封板，200%亦可读。人物和物资仅为场景示意，不是人口、库存或损失数据。

资产为项目原生SVG，地图母版64×80、锚点32,64，透明PNG128×160；近景1000×500。可用 `node scripts/render-south-bank-art.mjs` 重复生成，无外部图像裁切。
