# 第23轮只读实玩评估：让结果进入下一次决定

## 结论

本轮最高优先不是新合同或再调费用，而是完成「我作出了选择 → 结果真实发生 → 我看见并核对结果 → 带着结果回到下一窗口」的阅读和决策闭环。

目前合同前的成本、失败与机会成本已经充分，然而决定之后的结果只在当前年短暂出现。快速播放会越过预警，跳转后的回顾只按上一窗口人物行动组织，遗漏同一十年的重要世界变化。追查一条来源后也没有返回原年度/回顾的位置。玩家做了决定，却很容易没有看见决定怎样改变了接下来的问题。

本轮采用：已发生记载持续保留，自动播放遇实际新增记载时停留；新增“下一条记载”按原引擎逐年算到真实新记录或窗口边界，不预读；来源和只读回访回到原阅读位置；边界可重读十年回顾。条目提供真实地域定位，当前世界的可用行动负责下一步，不新增推荐或自动派遣系统。

## 两条自然路线

### A：准备充分的复核成功

0年联合建站 → 10年继任招募 → 20年主角B4完整复核、林澈D4免费预警 → 30年主角共享方针、林澈E4原学徒职责改排 → 40年。

- 第3年建站、第7年培训、第12年远港分站、第14年危机预警均自然产生。
- 第22年复核成功，但正确保留“第23年尚未结算”。第23年实际四地损失为零。
- 第31年方针与职责改排兑现，次年年度页重新只剩无新事件的空白说明。
- 40次年度推进中，36次仍处于 playback，其中26年只显示同一句“这一年没有新制度事件”。这不是引擎没有结算，而是界面没有持续告诉玩家这一段已经发生了什么。

### B：未准备的紧急复核失败

0年明确放弃 → 10年自愿招募 → 20年主角B4紧急复核（真实55%）、林澈D4居民传讯 → 30年查看B4后续工作。

- 第14年出现“过于一致的水位”，自动播放按钮仍为“暂停”，没有为预警停下；第15年预警即消失。
- 第20年默认回顾只有11年招募，预警仍在折叠的3条原始记录中。
- 第22年复核真实失败，没有可靠结论；第23年才出现实际损失。D4=0.7725，E4/D5/F6=1.0，整体=0.9431；这是原型系数，不是人口/伤亡。
- 第30年原回顾已经承认失败、已付成本和危机损失，成功路线也已概括零损失；不能说旧版完全没有回收危机。真正缺口是分站、预警、维护等本十年变化的发现，以及核对来源后返回规划的路径。现有来源按钮仅按“查看本段来源1/2/3”编号。

## 本轮采用的范围

### 1. 同一段关键变化，跨年度保留

年度页优先放当年结果与紧凑的已发生摘要，再放大年号装饰或完整原记录。摘要涵盖本十年的已核实重要兑现、失败/取消、危机预警和清点，必要时包含上一窗口投入在本十年发生的分站/维护结果。普通空白年继续有“这段时间至今发生了什么”，不是不断追加一整页同样长的原记录。

窗口回顾将同一摘要放在“进入新窗口”前后相邻的位置，先让玩家看见对下一次决定有意义的变化，再保留已有按人物的回收与全部原始记录。标题应说明这是“已发生”，不要称预测、评估或精确功劳。

### 2. 来源/回访真的能回来

从年度或回顾进入来源、只读现场，保留临时返回上下文：屏幕、选中地域/角色、滚动位置、展开项和触发按钮。显式“返回第X年年度演变/第X—Y年回顾”。离开年度就暂停，返回也保持暂停，不暗中补走年份。刷新、导入或新局后不假装还保留已丢失的临时上下文。

### 3. 只定位真实地域，不新增推荐系统

记载条目仅提供真实地域定位和现有只读回访。到世界页后，当前阶段、角色和可用行动决定能否继续规划；不新增建议最佳合同、自动改派或替玩家消耗取证的逻辑。播放阶段不能绕过介入窗口；条件不足与角色名额仍由现有现场和合同解释。

### 4. 推进到实际新记载，不查看未来队列

“下一条记载”从当前状态依次调用原年度推进，比较实际已存历史的新增记录，到新转折或下一窗口停止。自动播放同样只在结算后认出新记录并暂停。显式“略过逐条阅读，到下一窗口”保留原快进语义，最终进入含全部已发生转折的回顾。三条路径不能改变相同年份的世界结果。

## 范围取舍

- 不建议本轮改费用、概率、种子、年度源项或灾害结算。已有失败自然路线和后续恢复合同足以支持完整体验。
- 本轮采用自动新记载停留，收益是预警与兑现不再仅闪过900毫秒；代价是自动播放需要更多次继续。因此按钮提前说明会停，保留显式整段快进，不增加模态弹窗或强制逐条已读。停留必须与持续记载及回顾配套，单独暂停仍不能修复来源返回。
- 本条已存结果正文、失败不退款、不可逆损失和未结算边界应默认可见；不要把全部完整因果档案、重复合同与人物回顾也一并展开。通用责任解释可按需阅读。
- 不给未来待结算事件着色成成功/失败，不展示概率抽签值，不用当前服务倒推过去损失，不把不同规则旧档的新系数补齐。
- 下一步去向不是免费自动改派，不消耗也不退款调查，不改变锁定快照。
