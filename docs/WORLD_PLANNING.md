# 世界入口：先选谁，再读什么

## 实际问题与有界改进

自然路线中，第20年主角在B4复核、林澈在D4安排预警后，第30年世界仍选林澈/D4。林澈不能签署D4方针，首屏因而显示“查看D4历史”，而主角仍有真实合同。390×844下角色切换在页面约1881px处；第20年320宽/200%文字时在4207px处。问题是决策条件被隔开，并非缺少更多世界说明。

世界入口应保留地图和坐标列表，把唯一角色选择器放在主要入口附近。当前角色没有合同但另一当前可用角色有合同时，提供明确的“以主角查看 D4 方案”。只有玩家点击后才切换并进入免费阅读，不自动改派、不锁定，也不动已有草稿。多个候选沿用现有角色顺序，按钮写出具体人名，角色选择器仍保留全部可用角色。

## 纯模型接口

`getWorldPlanning(state, cellId, actorId)` 只返回本地公开规划事实：

- `readOnly/year/cellId`：上下文。
- `actors`：真实当前可用角色，保留 `getActors` 顺序。每项有 `id/name/localContractCount/draftStatus/budget/budgetStatus`。
- `selectedActor/otherActors`：同一返回值内的角色视图，不引用原世界对象。
- `draftStatus`：`unassigned/locked/passed/unknown`。真实锁定附 `draft:{cellId,actionId,title}`；无效草稿不伪装成未安排或放弃。
- `localContractCount`：`getActions` 的真实合同数，未知为 `null`。仅表示可以阅读的合同数量，不保证证据、余额、同格安排等锁定条件已满足。
- `budgetStatus`：`shared/per-scene/unknown`。现代共享预算取自 `getInvestigation`，耗尽为0；受损为null。旧每现场存档返回null，不从世界状态猜测UI会话预算。
- `primary`：`{kind,actorId,label}`。`scene` 读当前角色现场，`switch-scene` 建议明确切换后阅读；仅当前合同数严格为0时允许替代。全体已知0合同用 `history`，未知用 `unknown`，不得把未知当无行动。
- `notice/budgetNotice`：免费切换与调查规则边界。

非规划阶段、非法地域或未知/当前不可用角色返回null。调用者不可把null当作授权切换，亦不可自动替换成首位角色。点击时须重新核对当前世界、地域和目标角色，防止旧入口沿用到新窗口。模型本身不修改UI或世界。

## 信息与兼容边界

不新增规则标记，不改数值、概率、调查、证据、锁定快照、年度内核或结局。只读取公开行动、当前角色、真实调查支付与草稿。既不读取种子、随机结果、未来快照、未读材料正文，也不返回那些字段。合同数与角色状态不能解释为预测或最优策略。

林澈入局后须到 `availableFrom` 才出现。她的拒绝和主角独有方针照旧。现代调查按每角色每窗口共用；真正旧producer的每现场预算不混算。切换不退款、不复制证据、不解除锁定、不替换草稿、不自动放弃。回放/结局继续使用原入口，不显示规划建议。

## 验证范围

模型测试覆盖自然0/10/20/30年、真实双角色与Y30本地零合同、真实锁定/放弃/受损草稿、预算耗尽、重复只读切换、真正旧producer与旧每现场存档、非法身份/数据、无行动地域、非规划阶段、敏感未来字段抛错getter和返回值脱离原状态。UI尚须单独验证显式点击、导航后的上下文失效、真实键盘焦点及320/390宽的100/200%字号布局；模型测试不代表这些浏览器检查通过。
