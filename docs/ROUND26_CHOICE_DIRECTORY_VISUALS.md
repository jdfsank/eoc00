# 第26轮：完整合同目录的视觉与只读导航验证

## 范围

本轮针对真实试玩发现的纵向导航负担：原生200%字号下，点击“先看方案 · 免费”后，仍需越过多段前导说明才会遇到合同。第25轮的世界角色选择器、合同数与真实预算已经存在，本轮不重复声称它们缺失。

新增目录是完整合同的阅读索引，不是第二套执行卡。保留全部原始故事、完整合同卡、成本风险、取证规则、危机比较和末期主角唯一名额说明。目录项使用真实完整合同名称；点击仅定位并聚焦原卡，之后玩家仍需主动进入免费预览、审阅、锁定和统一提交。

## 样式

- 目录以轻量边框、下划线和向下箭头区别于原合同卡。
- 当前角色和真实剩余调查轮数就在目录上方，附明确的免费定位边界。
- 目录合同名使用1rem，原生字号16px/32px自然翻倍；没有在大字模式下缩小字号。
- 单项至少48px高，长名称自然换行，保持完整，不用省略号或行数截断。
- 目录项键盘焦点与原卡定位焦点均明确可见。
- 无固定高度滚动框、粘性覆盖、隐藏风险或对原故事的删改。

## 正式脚本

`node scripts/round26-choice-directory-visuals-test.mjs`

默认证据位置：`playtest-output/round26-choice-directory-visuals/results.json`。
可用 `ROUND26_VISUALS_OUTPUT` 指定独立测试根目录；浏览器端口4213。

覆盖：

1. 从真实种子0新局自然进行0→40年，使用40次真实逐年按钮，不注入阶段或导入主路线世界。
2. 第0年D4、第20年B4、第30年D4和林澈B4，各自检查320/390/430/1280标准，以及320/390原生200%。
3. 目录和原卡的ID、合同全名与真实行动集合一一匹配；当前角色和调查余额准确。
4. “先看方案”真实落点首屏至少可见第一项完整目录标题。此目标不是全部目录或完整合同卡首屏。
5. 所有目录项定位后，原合同标题在视口内、原卡获得可见焦点；免费预览返回同一原卡焦点。
6. 鼠标双击、同物理坐标连续触控、键盘Enter、重复进入与真实锁定草案状态。
7. 未知合同ID和非AVG过期目标失效；没有跳屏或改变世界。
8. 每一步对完整内存世界与真实保存世界逐字核对。目录、布局、预览、返回不花调查轮数、不改变草案或随机结果。
9. 无合同地点不出现虚构目录；真实旧版producer导入仅用于独立兼容性检查，核对每现场预算随真实调查减少、换现场不串用。
10. 结局320/390、标准/大字仍可读，且没有规划目录。
11. PNG保持原始视口像素；无横向溢出、丢失素材、运行时错误或热更新；整轮源码哈希一致。

## 开发自检发现

真实Chromium的目录双击可在第一次滚动后让第二次点击命中另一张原卡。一次复现从“商会独资”目录误开“官署独办”预览，世界未变化但不是预期的只读定位。

记录捕获阶段的pointerdown/up、mousedown/up、click后确认：鼠标第二次click的detail为2；固定坐标双触控的第二次兼容click也为2，但touch pointerId已经改变。因此连续点击保护应针对同一连续点击序列，不能依赖相同pointerId，也不应笼统屏蔽正常键盘Enter和后续主动点击。脚本同时验证这些边界。

连续点击保护的首轮回归还发现：仅在click阶段阻止预览不足以保住原目标焦点，因为第二次mousedown已让另一卡或空白区获得焦点。保护需要恢复最初定位的合同卡，并覆盖没有data-action的落点。正式脚本对原目标焦点和随后的正常键盘激活分别断言，不能只以世界未变或没有跳屏视为通过。

## 结果

2026-11-06，最终冻结版本完成全部 **1475 / 1475** 断言，80张原视口PNG，40次真实年度推进。没有运行时错误、缺失素材、横向溢出或热更新。src运行前后SHA256均为：

`013ebb32735202d690b7ed6ebe12f5a48d7fce0ba3d3920339a26e0c27c864f8`

测试实际记录20组第二次点击落在非action元素的序列，全部保持原合同焦点且无意外蓝色选区；随后正常单击和键盘Enter仍能进入免费预览。未知合同目标和非AVG过期目标没有跳屏。旧版每现场预算经过真实调查后D4为2/3，切换B4仍3/3，回D4仍2/3，没有误称共享窗口余额。

主路线真实结局仍为“许多人签署的历史”，回收共享方针与未来校验的实际兑现，并保留第23年损失不可抹除的说明。结束后不渲染规划目录。
