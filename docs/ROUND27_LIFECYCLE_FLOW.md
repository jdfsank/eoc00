# Round 27 lifecycle flow regression

Run `node scripts/round27-lifecycle-flow-test.mjs` from the repository root. Uses local Vite port 4225, repository/public assets and actual headless Chromium controls. Default report: `playtest-output/round27-lifecycle-flow/results.json`. `ROUND27_FLOW_OUTPUT` overrides the output directory.

## Scope

- A new seed-0 run is created through Settings. Four actual planning windows and all forty individual annual-step clicks lead to the ending. No browser API writes, injected state, forced year, or fake timer is used.
- Every investigation purchase, lock, pass, commit and annual step is compared with the unchanged current simulation kernel. Read-only navigation is checked against the complete in-memory and persisted state, not selected fields.
- The sidebar shows draft counts only in planning. Playback and ended copy is checked exactly, without a new-planning control or false empty count.
- Actual source chains retain exact original titles and prose. Additive stages match the pure public-provenance helper, including distinct scheduled and resolved cards for the same contract. Source/reopen/keyboard-return loops retain world, selection, screen, scroll and focus.
- The final policy checkpoint repeats the existing verified recollection opening exactly. Original outcomes and responsibility prose remain intact. Refresh preserves the entire world.
- Separate, clearly labelled genuine historical-producer file imports cover failure, cancellation and pre-handoff ending rules. These are not represented as natural browser playthroughs.
- Malformed, duplicate, foreign-parent and future negative controls operate only on detached copies passed to pure helpers. Such copies are never imported.
- Native 200% typography is exercised at 320 and 390 CSS pixels with actual keyboard source/return operations. This is not OS zoom, physical-device, screen-reader or human balance certification.

The report retains checks, runtime/network errors, forty annual steps, source-stage witnesses, viewport metrics, screenshot paths/bytes/SHA256, and recursive `src` path-plus-byte hashes before and after. Failure exits nonzero and captures a screenshot; source and historical tests are never rewritten by this script.
